The upstream CLI's [manifest generator](https://github.com/0xobelisk/dubhe/blob/04700a9a13e6f279be3709e84bf4ad24b4349af3/packages/sui-common/src/codegen/utils/renderMove/generateToml.ts) still emits older Sui/tag dependencies. Our pinned manifest is intentional. `dubhe test` ultimately invokes local `sui move test`; it does not remove the need for a compatible Sui compiler. Actual testnet receipts and gas measurements must be reported separately from Node/Mock/unit tests.

On 2026-10-28 the official Testnet JSON-RPC endpoint actually rejected `sui_getChainIdentifier` with its deprecation/migration message. The [current official migration guide](https://docs.sui.io/develop/accessing-data/grpc/grpc-migration-cookbook) confirms the migration to gRPC/GraphQL. This package therefore uses exact Sui SDK 2.16.2 gRPC for I/O and modern transaction resolution, retaining real Dubhe raw builders and offline signing only. A live read through that transport verified chain `4c78adac`, the published testnet framework's typed-object ABI, and a finalized Clock result. That read-only evidence is not a deployed procurement or trade test.

Subsequent [real validation](validation/20261028/README.md) deployed the independent package and finalized all nine transactions across fill/cancel/expire custody-fixture orders. The official [GraphQL migration guide](https://docs.sui.io/develop/accessing-data/graphql/graphql-migration-cookbook) and actual testnet introspection confirmed `EventFilter.module`, checkpoint bounds, `EventConnection.edges.cursor`, transaction digest, event sequence and raw Move-value BCS. Two filtered pages recovered all nine order transaction wakeups, including framework object creation, and a real opaque edge cursor resumed without repeating the committed event. Whole-public-chain checkpoint scanning is only an explicit fallback; neither GraphQL nor the general Dubhe indexer authorizes delivery without fresh finalized gRPC evidence.
