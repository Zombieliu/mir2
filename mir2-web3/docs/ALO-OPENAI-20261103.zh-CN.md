## 用户入口与模型选择

Windows 设置入口 `Numeron-Alo-Settings.exe` 由本人填写 OpenAI API key。默认 `gpt-6-luna`，可改模型名。保存后重启本地试用生效，当前角色存档不迁移、不替换。打开“伙伴 → 私人委托”，例如输入：

> 在附近打两只怪，再回来找我，途中别捡东西。

模型理解目标和数量，读取局部观察、有效的三条习惯与最多八条相关记忆，生成结构化目标。现有控制器持续走位、攻击、吃药、支援和撤退，Zone 仍独占游戏事实。支持跟随、最多三只附近普通怪物、固定安全点撤回和等待。未组队、主人不可见或怪物不可见时不会越界寻找。

模型不逐帧调用。每条新委托一次请求，无自动计费重试，一小时最多20次；上限按持久请求记录计数，删除记忆墓碑仍保留计数依据。调用设15秒超时、1024最大输出 token；GPT-6 设置 `reasoning.effort:none`。窗口显示模型计划、调用状态、实际参战击杀与阶段。模型生成的句子不算击杀或完成。

模型价格以[OpenAI Luna 页面](https://developers.openai.com/api/docs/models/gpt-6-luna)及[Terra 页面](https://developers.openai.com/api/docs/models/gpt-6.1-terra)为本轮读取来源。模型可换，质量、延迟和成本需真实调用测量。按 token 的例算不作为实际账单；已有人民币体验账本在出现调用后保持模型金额未知，待真实费用确认。

## 身份、记忆与权限

原身份、共同成长和模型运行配置继续分离。角色档案和成长进入 HMAC 导出，模型服务配置与密钥不进入。Windows Credential Manager 保存当前用户的密钥；metadata 只有六个配置字段，凭证目标绑定交付目录规范路径的 SHA-256。换目录需重新配置。helper 仅向父进程捕获管道读出本目录凭证，不接受任意目标或凭证参数。

私人委托复用原账号／角色 enrollment、owner admission、generation、worldEpoch、deadline 与撤销通道，新增 `instruct` 操作；文本不走附近聊天。key 只在独立 Actor 环境内，不传 Native、Gateway、profile、IPC、日志或归档。凭证样式的自然语言在 Unicode 规范化后整段拒绝。

主人指令、模型提案、实际观察分别标记来源。长指令最多两段、一次 SQLite 事务保存。检索复查有效状态和原始内容 hash，撤销、删除、清空或培养版本变化会取消旧计划并清掉内存引用。只有实际命中后对应死亡事件才增加参战击杀；未知 attacker ID、对象移除、模型自述不计数。抵达主人或安全点也检查实际坐标。

召回不等模型返回。死亡中断任务，复活后不自动续跑；重启显示旧委托已暂停，保留真实经历，重新委托后才规划。寻路按当前碰撞、占位、主人范围和每一步验证；遇到无法合法绕行的路径等待。原吃药、危险撤退和已确认自卫优先。
