## 模型与规则的分工

接入现有 OpenAI Responses 严格结构化输出，只建议“沿固定路线、狩猎、休息”。每次生活最多4个持久化阶段调用尝试，并和既有教学/委托共享每小时最多20次上限；没有每步、每帧调用。巡路建议在指定路点完成后结束；模型休息建议最多30秒，身体未恢复时仍继续安全休息。规则版本、角色/世界、期限、撤销或记忆变化会阻断晚到结果。模型不可生成资产、开放新地图、改变花费上限或裁定击杀。

只有服务器正式激活后，运行器才开始模型规划和生活行动。准备阶段拒绝、断线或超时不会生效；已提交的激活通知独立于主人后续在线状态，但仍绑定原 Actor admission、generation、签发事件、期限和有效服务端范围。重启后原生活暂停；主人明确恢复，沿用原到期时间、支出和唯一采购名额。

模型建议记为提议，游戏受击后死亡、真实回家和已核对的采购/赠礼分别记实际事件。成长 SQLite 与 `.life.sqlite`、`.gifts.sqlite`、`.supply.sqlite` 执行日志分离；模型凭据不进角色归档。

## Windows 操作六步

1. 启动包含本轮“自主生活”页的 Windows 本地试用 EXE，登录自己的角色。**本地 Gateway 和阿洛 Actor 运行器需要保持后台运行**；真人登出不等于可以关闭整套本地服务。下方交付入口与收据分别记录公共文件更新和旧记忆保留。
2. 点击游戏内“伙伴 Companion”，选择已授权的阿洛，进入第六页“自主生活”。先查看阿洛自己的血量、金币、血药、背包空位和负重；“待核对”不等于零，也不等于已经到账。
3. 需要补给时，走到阿洛相邻格、互相面对，用原交易窗口赠送金币或血药，由主人完成交易确认。阿洛不放出资产。以最终交易及实际钱包/背包变化为准；要购买当前40金币的一瓶药，钱包需要实际有足够金币，选择50金币授权不会发币。
4. 选择20或30分钟，点击“查看并确认生活授权”，核对地图0、x270–310/y595–645、回城点(288,616)、本会话累计50游戏金币和最多一瓶药，再确认。等待服务器激活；预览后取消不会授权，也不会因此调用模型。
5. 激活后可以离开阿洛视野，或让真人角色登出，同时保留后台服务。回来观察探索、战斗、补给、休息及实际计数。钱包余额与采购剩余额度分别显示；钱、药不足或背包满时，应等待主人处理，不靠卖装备补齐。
6. 需要结束时点击“停止生活”或“召回”，观察实际回家、停止并待命；结束或到期后需新授权才能再次独立出发。若只是重启运行器，原生活先暂停：回到同一个阿洛，点击“确认恢复原生活授权”，沿用原到期时间、已花金额和唯一采购名额；已到期的原授权不能恢复。未决赠礼或购买先核对原结果，不通过再次确认制造第二笔交易。

## 服务器裁定

Zone 消费移动意图时检查地图、目的格与跑步中间格；撤权后的旧排队移动也不能越界。失效授权只允许范围内向家靠近，停止新攻击和拾取。地图出口、传送、传统 WorldCommand 包装、普通无上限买物，以及魔法/弓箭等未覆盖动作会拒绝。当前首版只开放基础近战与确有的HP药。原 session 仍管理个人背包/存档，共享 Zone 管理位置、碰撞与可见性。

返程进度按服务器真实碰撞与当前动态占位下的可走路径距离验证，每步必须降低该距离；允许绕过建筑和当前挡路对象，不能兜圈。只读占位视图复用原Zone移动判定，既不扩大地图范围，也不放开攻击、拾取或传送。静态几何及有界动态距离缓存减少重复寻路，但不据此声称容量资格。Actor安全区标志变化会补完整快照。服务器真实拒绝的移动格采用3秒、最多64格的暂避记录，并有限重试或暂停。连续3次无路换固定路点、三点均堵返家、返家仍无路则明确暂停；到期/取消返程不被自卫追击覆盖。

主动狩猎从六格内取得目标，已在追击的可见目标可维持到十二格，并要求公开碰撞图上的实际路径不超过十二步；绕建筑过远的目标暂缓三十秒，避免走一步又放弃的来回振荡。已知0HP怪物尸体不作为活体占位；明确收到ObjectRevived后恢复为HP未知，不能靠移动或攻击包伪造复活，NPC即使0HP仍挡。诊断仅含观察坐标，不附名字或资产。

赠礼沿用原共享交易的邀请、托管、确认与结算。Actor 对外出金币/物品在服务器拒绝；只允许登记主人配对。锁定或窗口关闭都不算收到补给：最终成交包、同连接身份的后续完整快照、实际金币和物品UID增量共同匹配才记忆。未知赠礼跨重启保留，阻止新采购；取消交易独占一次行动，下一次再处理喝药、撤退或自卫。
