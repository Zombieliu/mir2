# 五职业1–100级装备与SLG资源盘点

盘点日期：2026-10-19。新产品规则为[100级封顶，满级开放新增SLG](LEVEL100-SLG-PROGRESSION.zh-CN.md)。本轮盘点本地Crystal导入数据与full资源包，生成候选和预览；没有修改运行等级、装备属性、爆率、存档或SLG开关。

## 1 结论

**现有资源可作为五职业男女1–100级装备编排的基础，允许共用造型与跨档复用。71–100级数据仍须补齐，尚不能直接上线完整100级成长。**

当前1628条物品中，有964条核心装备模板；这些包含职业、性别、动态等级变体，不是964套独立美术。对每条模板按100级及允许职业/性别解析后，检查图标、地面图、适用纸娃娃和基础/刺弓特殊动作集合，964条均有可引用资源。这不是逐级穿戴回放或实机战斗验收。

生成了820条分档分配位置，覆盖五职业、男女、1级武器/衣服，以及10–100级每10级八类核心装备。全部找到可用来源；其中22处重复使用本职业/性别成长中已有的世界shape，10处重复使用图标ID，另788处为来源候选。**788不代表788种独立外观**，跨职业共用与不同编号相同像素仍可能存在。

## 3 实际资源核查

full包索引共有1440个库，本次检查与装备相关的277个世界动作库及Items/StateItem/DNItems三个库。

| 库族 | 库实例数 | 计数含义 |
| --- | ---: | --- |
| CArmour | 59 | 普通身体库；不等于59套五职业独立套装 |
| CWeapon | 79 | 普通武器库 |
| AArmour | 25 | 刺客身体动作库，与普通身体shape配合 |
| AWeapon | 38 | 19组L/R双文件，不能算38套双刃 |
| ARArmour | 22 | 弓手身体动作库 |
| ARWeapon | 54 | 27组普通/S双文件，不能算54把完整弓 |

Items有5206个可画帧，StateItem有2380个，DNItems有5128个。这些是帧数，不是可用套装数。盘点按源渲染规则区分原始图标/地面图与动态解析后的武器/衣服纸娃娃；项链等首饰不要求具有世界动作。StateItem不用人为加男女统一偏移。

| 检查 | 结果 |
| --- | --- |
| 280份库manifest及索引SHA | 通过，0项manifest错误 |
| 567张PNG页，670,308,052字节 | 文件存在、PNG/IHDR头、尺寸和SHA文件名通过 |

备用库 **CWeapon/71** 总共831个槽位，女性死亡第8方向所需帧831越界；Die和Dead共引用同一个缺失帧。它未被当前964条模板或本次候选引用。后续分配备用武器时先排除该库，取得正确源资源并复验后再使用。全资源“全部完整”这一说法不成立。

另有62个世界库没有被当前装备模板引用，属于待映射储备，不能直接当作62套现成新装备。动作检查是源动作集合的帧引用核查，已包含刺客Dead女性双刃回到+416偏移、弓手AttackRange3回到基础ARWeapon库的补充引用。实际状态切换、骑乘、钓鱼、特效与混合叠层仍需实机验证；Rust当前动作枚举没有Range3，本次源资源通过不能宣称该技能已实装。

| 本服目标档 | 优先取材的源等级 | 处理方式 |
| --- | --- | --- |
| 1级 | 1级及以下 | 起步武器和衣服 |

| 60级 | 50级附近 | 延伸现有五职业素材 |
| 70级 | 55级附近 | 保留角色定位，允许同系列职业变体 |
| 80级 | 60级附近 | 高阶源资源重编属性 |

这是资源编排，不是直接换算等级或照搬数值。没有强制整10级换全身，也没有确定中文套装命名。源模板不能证明圣战、魔龙、战神、星王等国服名称在本项目中已有一一对应的完整套装。

## 5 普通获取、经济与交付缺口

964条中403条名称在原始掉落表被直接引用。其余不能直接认定为不可获得：动态职业/等级变体可能经母模板生成。反过来，存在掉落引用也不能证明怪物当前刷新、地图可达、默认内容配置开放、掉率和经济合理。

本次没有重算普通/极品爆率，没有证明每小时50万毛收入或33万净利，也没有得出每周十张月卡的变现能力。100级成长仍需连同经验、药费、修理、回收、交易需求和金币去向一起测算，掉落应按实际普通玩家刷怪路径验证。

full包本地资源通过不等于Thin包已携带全部动态装备或普通客户端能正确绘制。需要后续真实穿戴、八方向动作、攻击施法、受击死亡、掉落拾取、保存重登和正式交付验收；本轮没有启动游戏、运行Cargo或发布安装包。
