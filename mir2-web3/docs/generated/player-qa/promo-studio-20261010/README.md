- 原始过期录制、刻意使用不存在 FFmpeg 的编码失败保留于开发机 `C:/mir2-promo-studio-20261010/captures`。前者未用作成片；两次专用 Chrome 均已关闭。没有删除失败重新定义成功。

原始帧、视频、完整录制回执及成片在上述开发机目录，未推送进 Git。浏览器证据仅包含自有普通 QA、公共观战和工作室资料；私有登录记录未复制入项目。
