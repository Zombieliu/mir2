Asset audit scans 158 source files and 2,443 configured/static indices in nine
UI libraries. 2,361 drawable frames match original pixels. 82 original empty
slots remain separate. Preview arithmetic, arbitrary server-selected icons and
computed service titles are not fully inferred. The source scan does not prove
all screen states, inputs, or animations correct.

Run from apps/web:
`npm run audit:native-ui-assets -- --dataDir <Crystal-client-Data-directory>`.

`native-ui-assets-20260921/audit.json`; NPC implementation limitations are in
`npc-service-ui-20260921/README.md`.
