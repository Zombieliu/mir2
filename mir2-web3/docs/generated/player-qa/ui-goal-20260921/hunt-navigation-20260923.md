## Changes

The persistent card previously rendered local hunting areas as text only, and
the entrance navigation intent explicitly rejected same-map destinations.
The card now offers `前往狩猎区域 · 自动寻路`. This action remains available when
a relevant live monster enters or leaves view. It uses the selected quest's
unfinished authored kill, current map/epoch and actual respawn metadata.
Cross-map entrance navigation retains its existing distinct target kind.

The shared UI and native consumer both revalidate the specific unfinished
kill and its imported center/radius. Completion or primary/map changes while
the pointer holds the button invalidate the queued request. Completed or
missing kill counters do not infer travel from a remaining class-practice flag.

Native travel uses a single bounded A* search to a reachable tile inside the
imported square spawn region. The heuristic is Chebyshev distance to the square;
the existing 250,000-node budget is unchanged. The route keeps its area during
dynamic-obstacle replanning, so an occupied selected endpoint can be replaced
by another reachable area tile. It does not promise the exact spawn center.
Already inside the valid area means no travel is needed. Both immediate and
acknowledged arrival stop the route and show `已到达狩猎区域，请选择怪物战斗`.
Only ordinary walk/run is sent; no attack, teleport, grant or task completion
is generated by this navigation action.

The diary's `ReadyToTurnIn` label is now `可交付`. The old `Complete` label
did not mean that the reward had already been claimed. Backend quest content,
rewards, progression and saves are unchanged by this patch.
