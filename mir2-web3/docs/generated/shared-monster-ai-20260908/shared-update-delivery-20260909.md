# 共享更新接入记录（2026-09-09）

范围是个人模拟已有的 47 个专属怪物模块及它们依赖的共享更新、命中、死亡、召唤和存档链路。47 不是怪物总数，也不是整个游戏的完成度分母。

## 实现范围

- 共享 Zone 处理玩家、真实宠物及怪物状态；个人 Session 保留账号、角色和个人资产职责。
- 延迟攻击保存来源、受害者的生命身份，区分玩家复活代与怪物实例代。尸体仍在场时可完成原版允许的攻击，真正移除或同 ID 重生后不会重新绑定旧攻击。
- 怪物攻击真实宠物，直接改变宠物 HP；不会用主人的 Session 冒充受害者，也不会给被杀宠物的主人虚构击杀奖励。
- 范围伤害分别保留命中时重查位置、发射时锁定目标、视线资格，以及 Attacked / Struck 的源区别。
- 周期毒、减速、麻痹、红毒、冰冻、眩晕、流血使用独立共享租期。眩晕阻止攻击而允许追击；冰冻阻止两者。树根麻痹跟随真实根节点的寿命。
- 普通与专属怪物消费共享目标关系。BoneLord/Zuma、Meow、SnowWolf、RootSpider、Yimoogi 的子体继承带生命身份的目标；SnakeTotem 满员时仍能改变敌怪后续实际行动。
- Hell 与 Yimoogi 的父体/分身关联带实例身份，防止旧子体死亡或同 ID 替换影响新对象的阶段、目标或掉落。
- checkpoint 与事务 fork 保存这些共享状态。AOI 观察者使用真实对象身份接收攻击、位移、中毒、死亡和掉落。

登录持久化混合日志中 4 项通过；Q1–Q4 在获得 4 份鹿肉后失败，修正剥皮目标与尸体到期后单独复验通过。该混合日志还保留旧 Gate11 失败，后续 Gate11 2 项复验通过。首次网关全量的 7 项失败均已有通过的复验，但表中各组有重叠，也有明确的版本边界，不能相加当作唯一测试数，不能描述成整个项目最终源码重新跑过全部测试。尸体修正后已另外完整重跑模拟端。详见 [验证清单](shared-update-verification-20260909.json) 和 [最终源码哈希](shared-update-final-source-20260909.json)。

首次全量模拟测试编译之后补上了 HellKnight 的 Struck 免疫及测试；普通 Attacked 仍可伤害它。随后网关回归发现跨 Zone 恢复把 Crystal 药水治疗值 30 覆盖成兼容值 35，已改为仅对缺少治疗数据且无精确模板身份的旧物品回填默认值，并通过库存和实际交接测试。四个登录持久化用例改用各自独立的恢复目录，保留所有权校验及旧目录。

收尾还修复了两个真实掉落问题：AOI 视野移除不再误删共享地图物品；收据缓存按实际 Zone 和有序 / 本地序号域隔离，本地序号从共享 checkpoint 状态分配，避免跨区新运行时重置后重用旧成功回执。已验证日志序号在主备两侧保留，但 Direct、未认证请求和备用重放的外部写入权限始终为 false。新增专项和独立复审通过。

任务长测还发现，测试错误接受旁边尸体的剥皮回执，且共享普通尸体缺少到期回收，未剥皮可永久阻塞刷新。现已校验准确目标 ID，并在 180 秒后退休尸体、保留刷新期限；网关区分内部 ID 预留与公开对象，防止无人观察时旧尸体回流。死亡后与到期移除后的 checkpoint、重复 tick 及零接收者同步均有回归。原版刷新组时钟与新 ID / 旧尸体共存，以及旧 checkpoint 中无到期字段的既有尸体迁移仍开放；见 [尸体复审](corpse-expiry-review-20260909.md)。

远端交接的调试版目标 StartGame 超过默认 5 秒 RPC 时限；诊断使用较长时限时整条交接 12.65 秒完成。仅该测试设 30 秒期限，生产默认值和原超时专项未改。发布版冷地图启动性能仍需测量，不能宣称生产耗时问题已修好。

网关唯一跳过项 `postgres_store_is_shared_across_gateway_instances` 需要未配置的 `MIR2_CHANNEL_IDENTITY_TEST_DATABASE_URL`。编译仍有可见性、弃用接口和未使用项警告。首次失败、再次 RPC 失败与最终修正日志均保留，不将失败快照标记为通过。

测试包括真实召唤 → 只剩宠物可被攻击 → 专属攻击/毒/推移 → 死亡或退休 → 存档恢复；另覆盖图腾改变真实行动、两秒召唤启动锁、角色复活后旧攻击失效及独立环境震击。

## 不等同于 Crystal 全游戏认证

此记录不将“有入口”或“测试通过”解释为原版全部物种认证。完整 pet PvP、Hero、DragonSystem、原版 LastHitter/EXPOwner 仲裁、完整寻路/占位及随机流仍有源差异；通用原生怪物回血也不是本次个人专属模块搬迁的既有基线。

网关的跨进程崩溃时收据与保存原子性，以及极端延迟旧死亡缺少原 ZoneKey 的场景，仍单列后续工作。正常离区流程先结算再保存。

本轮没有生成 Windows 安装包，也没有进行实机视觉、操作手感或人工最终验收。`globalComplete=false`，`accepted=false`，不报告整个游戏的百分比。
