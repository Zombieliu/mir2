# W15 offline funding geometry supplement

This independent supplement preserves five public originals from the external offline investigation. The [original W15 archive](../README.md) and its [40-original manifest](../copied-evidence-manifest.json) retain their original bytes and failed verdict: 42 prepared, no capacity measurement or acceptance. This supplement does not replace that archive or qualify a production pass.

The [static route proof](static-route-proof-v1.json) uses the pinned real map0 collision pack with closed doors and all 69 authored transfer cells blocked. From the four actual selected start/target pairs, global range1 routes exist but no route stays inside target AOI16. Minimum static radii are 23, 18, 20 and 24 for targets 206500, 206521, 206708 and 206706 respectively (57, 27, 26 and 36 steps). These larger-radius routes explain the original visibility loss; they are not authorized moves or live safety evidence.

The [geometry result](geometry-result-v1.json) separately reconstructs the final target 206320 planning view: seven retained shared points, 27 occupancy rows and 69 authored transfers. The pinned helper algorithm reproduces 604 explicit cells and matches all 128 published prefix cells, yielding the original 700-entry dynamic obstacle array. All nine range1 goal cells are covered by the still-valid historical Scarecrow 206604 at 275,600; no memory or TTL was removed.

Earlier complete dynamic planning views were not retained. Their nearest spectator-frame and sampled 20-second union projections are explicitly **not exact client replays**. Sampling cannot establish every intervening receipt, identity change or trail point. A found projected route is only a frozen offline candidate, and a missing projected route does not prove the actual historical world was unreachable. The four static local-map results have the narrower collision/transfer-model scope stated above.

The [review summary](review-summary-v1.json) preserves authoring history: the first analyzer invocation exited 1 before producing output because a point-object API was called with separate coordinates. The script was corrected; subsequent syntax and offline executions exited 0. This is an authoring correction, not a production pass, live rerun, fresh Root qualification or revised W15 verdict. Archived tools are [analyzer](analyze-v1.mjs) and [static connectivity query](static-connectivity-v1.mjs).

The [independent copy manifest](copied-evidence-manifest-v1.json) pins all five raw copies and the unchanged original archive files. Content review found only public scalar geometry, paths, hashes and tools: no complete recordings, Store, pool, ledger, keys, binaries or raw Gateway logs were copied. No production source, original archive file, budget or guard was changed.
