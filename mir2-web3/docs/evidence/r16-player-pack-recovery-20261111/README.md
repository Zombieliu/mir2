# 人物包两次网络失败后的恢复

基于 R16 `0d95d5cc5cd44a806a4913b507d4033c89231205` 的生产候选 `0d95d5cc5cd4-r16-player-recovery-2cf7848a`。前一生产版公网人物包两次读取中止见[正式回执](../r16-font-fill-20261111/production.md)。本记录证明恢复行为，不宣告网络长尾或整体 1:1 已完成。 修复现已发布为 `cd6410be74`，最新公网分项、首步失败和共享 HUD 状态见[正式发布](production.md)。

旧版初次人物包两次读取均失败后返回 null，当前角色界面不再重读。候选在此时先允许原有散图正常加载，间隔一秒后以同一固定 URL、reload 再读取一轮。每轮仍最多两次传输，保留 20 秒响应头、8 秒停传和 45 秒正文上限；成功后继续校验完整长度和 SHA256，未更换帧或图片。

只有网络异常或期限取消会触发这次后台恢复。明确 HTTP 错误、Retry-After、截短或哈希不符的数据不会因此重读或发布。观察者取消后无迟到回调、无后续恢复计时；共享下载可继续供其他观察者使用。持续网络失败最多四次读取，不循环请求。

## 检查与真实游戏

71 项定向和相邻 Node 检查、生产和 TypeScript 构建通过。固定复用 27 项生成输入，18 项当前源码覆盖经 SHA 核验，Rust 运行包未重编。命令、构建输入和结果见 [receipt.json](receipt.json)。

真实 Chrome、实际 HTTP 服务和隔离普通 Gateway 中，第一份人物包发送 49,152 字节后停传，第二次不发响应头，后续恢复正常；两个等待均由实际产品期限取消，未拦截浏览器网络。受控服务将覆盖散图返回 503，但正常 CDN fallback 仍可运行，因此不把旧版截图写作人物完全不可见。
