# R16 Web 游戏帮助的十语对齐

游戏里的 `H` 帮助窗使用 [Windows R16 的原顺序与词库](../../../apps/game-client/client-bevy/src/crystal_ui/localized_help.rs)。三页快捷键说明用当前键位，标题与正文随所选语言显示；42 页正文在九种非英语语言使用已有翻译，英语继续使用原版位图。支持阿语从右向左，同一页与语言的阅读位置在翻页、关闭再打开后保留。

隔离 File 世界用正常登录、选角和进城，分别用简中、阿语和英语打开帮助、翻页并正常退出。简中和阿语匹配 R16 词库与字体，英语加载原 512px 位图。专用滚动探针缩小正文视口，真实滚轮到 40px，翻页及关闭重开后位置保持。正常布局截图单独保留。三轮无移动或战斗请求，页面、控制台和 HTTP 错误均为零。
