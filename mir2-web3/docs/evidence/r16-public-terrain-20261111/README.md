## 公网旧版复现

在正式版 `d3e9ebfa6b` 用普通桌面 Chrome 和官方 Testnet 钱包走完扫码签名、选角、比奇出生区地图校验、移动及退出。进城回包后 3.26 秒开放输入。走一步后的 22 秒采样里，243 个可见地面图片没有一张完成解码。画面只剩名称和部分界面。该窗口内 102 条同源地砖请求涉及 86 张图，没有收到响应头。后续少量同源请求收到 HTTP 200，退出前没有记录到完整正文。这个探针漏记 `/hotlink-ok` 直连回退，结论限于同源请求与实际画面。 [旧版回执](public-baseline.json)

同一个已注册 Service Worker 的普通登录页各读一组 12 张 PNG。同源和固定 CDN 都全部解码。同源耗时 0.20–1.46 秒，固定 CDN 耗时 0.48–0.60 秒。样本证明源文件可用，进城时的大批请求另行观察。 [配对读图](public-baseline.json)

## 地砖包

`f905435616` 在登录成功后的开门或选角时预取一个文件。它含出生点附近 124 张原始 PNG，逐张与固定 R16 资源清单核对大小和 SHA256。完整包为 439,896 字节，客户端按固定摘要验证后在比奇 `0.map` 的现有地面层使用这些字节。包外贴图、建筑、角色及其他地图继续使用现有来源。地砖包和地图几何各自获取。损坏、超时或单图解码出错时使用普通贴图。 [包元数据](../../../apps/web/lib/generated/r16-entry-floor.json)

## 正式发布

正式域名读回 `f905435616`。发布流程在切流前后核对静态地图和地砖包的长度、摘要及扫码会话待确认状态。简体和繁体在独立普通 Chrome 中分别确认出码、待确认、取消后停止轮询。 [候选构建](https://github.com/Zombieliu/mir2/actions/runs/42889037760) · [正式切流](https://github.com/Zombieliu/mir2/actions/runs/42890332451)

一轮新的普通 Chrome 使用官方手机尺寸 Testnet 钱包完成真实扫码授权。地砖包在登录回包后 5 毫秒请求，3.82 秒读完约 298 KB 传输数据。此轮创建角色，地砖包在进城回包前已到。进城回包后约 3.30 秒采样，221 个可见地砖全部解码，其中 219 个直接来自包。实拍有原图地面。走到 `(289,616)` 后，可见 243 个地砖均解码，其中 239 个来自包。正常注销回选角。 [公网签名与网络回执](public-release.json)

首屏可见的 39 个建筑等地图对象没有完成解码，人物贴图也未绘出。进城回包后约 12 秒的记录仍未观察到地图对象解码。这次通过比奇出生区地面及一次默认桌面浏览器移动。继续核对建筑、角色、较快选已有角色及实体手机。 [首屏和对象观测](public-release.json)
