## 问题与变更

[上一轮公网失败](../r16-login-door-retirement-20261114/production/README.md)实际记录：运行包
应用源 8 秒无响应头，备用源再等 120 秒仍无响应头后直接结束，未尝试新的应用源读取。
主动字体预热在运行模块成功之后才开始，因此该轮六字体缓存 0/6 不能全部归因于字体队列。

现在对多个配置源的首次读取各给最多 8 秒响应头探测，再使用原有一次新读取额度。
双源都无响应头时回到先前停滞的源；应用源返回 404/503 而备用源较慢时，备用源仍得到最终
120 秒响应头预算。单源预算、15 秒正文闲置、32MiB 上限、正文绝对期限和编译 / 初始化
边界保持原值。实际双源每组最多 3 次读取，既有调用者额外组仍最多一次；最终头截止仍终止，
不会消耗额外组来无限重试。角色离场或调用者撤销后不再开始新请求。

本轮仅改运行包下载器与检查脚本；没有改字体字节、Worker 字体策略、寻路规则或服务端。
