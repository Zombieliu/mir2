## 本轮修正

- 先等待现有 game/HUD 预取尝试结束，再开始大运行包；该 Promise 只表示尝试结束，不能作为 113 全部成功的依据。
- 二进制优先使用受 manifest 校验的应用源版本路径，保留同版本、同包的 CDN 后备。glue JS 仍使用固定发布地址；不使用会跨版本变化的无版本路径。
- 读取采用单个受监控流交给 compileStreaming，没有重复拼接一份完整正文。JS import 独立 120 秒；首源头部 8 秒后进入后备、最终源头部 120 秒；正文仅在等待读取时计算 15 秒无有效数据，另有 600 秒绝对上限与 32 MiB 解码字节上限。编译不消费流与初始化均有独立 120 秒期限。
- 已开始的 wasm-bindgen 初始化若超时，要求新页面，防止迟到 finalize 与同模块重试并发；等待 canvas 时过期的调用不会进入 default。
- 六份原字体在模块就绪后预取，保留全部字形、Unicode 回退、两任务并发、完整正文缓存和现有字体恢复规则。

源码和 WASM 包未改变游戏规则、存档、钱包权限或服务器裁定。固定三个 WASM 为 31,441,753 / 16,607,010 / 32,369,572 字节，均在 32 MiB 内。
