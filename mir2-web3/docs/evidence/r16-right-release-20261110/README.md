# R16 Web 右键释放、设置与移动怪物追击

2026-11-10 对照已提交的 Windows R16 `0bd1b138b4`。本机生产 Next 构建 `_V3KsRrYop-O-w11tmE5J` 配对已有 `bevy-48c1f266331da4cb`、固定地图与 File Gateway。测试从 Chrome 正常游戏界面输入可信鼠标事件，使用天然怪物和正常保存的隔离档。回执记录构建、输入、WebSocket、落点和存档的校验值。 [机器回执](receipt.json)

## 经典右键

从比奇 `(298, 269)` 右键按住鸡图像上的同一像素，底下是可行走的空地。旧 WebGPU 与共享 WebGL2 在松手前均收到首步回执。松手后至少 405.8 和 378.2 毫秒时各补发一条 Run，服务器又确认了位移。候选仍各收到按住期间已发出的一步。随后 1.65 秒内两路均无新移动，注销档读回 WebGPU `(297, 270)`、WebGL2 `(296, 271)`。鼠标边界和实际出站帧取自同一 Chrome CDP 单调时钟。 [松手后的角色位置](classic-right-release.png)

初版仅修长按时，经典短按仍可在起步降为一格后补发 Walk。最终版在共享 WebGL2 实测静止 1481 毫秒后短按 48 毫秒，只在释放区间发出一次 Run。服务器确认降为一格 `(297, 270)`，观察 1.65 秒无第二条移动，注销存档读回该位置。

## 从 HUD 关设置后继续操作

旧版点击 HUD 打开设置，弹窗拦截了属于原按钮的释放，关闭后战斗控制器仍记录 `hud` 按住，下一次地面右键没有出站。最终版在同一 WebGPU 会话中点开设置、启用新版移动、关闭弹窗，原按钮令牌已释放。首次右键点地三次收到移动回执，其中两次移动在松手后发出。角色到达目标格 `(294, 266)` 并正常注销读回。 [关窗](options-closed.png) · [寻路到达](new-move-arrival.png)

## 追击真实移动的野怪

同一 30 级法师从 `(262, 410)` 单击十格外的奥玛一次。WebGPU 和共享 WebGL2 都收到同一目标两次天然移动，从 `(272, 411)` 到 `(271, 410)`、`(270, 409)`。各七次单格 Walk，其中五次在目标首个移动回包后发出。两路都从 `(269, 408)` 命中奥玛的新位置，约 5.1 秒收到伤害回包。注销档读回 `(269, 408)`。 [伤害回包后的画面](moving-oma-hit.png)

另一个样本中，148 个可用画布采样点先命中前景栗树，6 个点落在画布外。保留该样本的采样回执，下一轮与 Windows 的逐像素命中核对。
