## 最终修复与定向回归

现服务器按实际静态碰撞及当前动态占位的可走路径距离逐格降低验证返家，复用原Zone占位判定，允许必要绕行。Actor安全区变化补完整快照；真实拒绝的移动格临时隔离3秒、最多64格，重试有界并可暂停。连续3次无路更换固定路点，三路点均堵则返家，返家再3次无路则明确暂停；到期/取消返程不被自卫追击覆盖。主动目标有实际路径十二步上限，已追击的可见目标保持十二格，过远路径暂缓三十秒。明确ObjectRevived将旧0HP怪物恢复为HP未知；移动/攻击包不复活。诊断只含观察坐标，不暴露名字或资产。

第四轮`lf-44cc9d5021`未通过：到期后(288,637)受真实对象占位阻挡，静态距离拒绝必要侧绕，控制器三次失败后如实暂停。最终动态占位修复后，[三个旧卡点回归](targeted-homeward-return.json)已通过；普通人工准备后取消生活，控制器均回到(288,617)安全区，零模型调用、零支出，明确不是二十分钟自然到期。

最终Gateway SHA为`7d0f109717150ebfacb205db403c19bccf58ad9eec296e78bb63e0e221c6070a`。同版本完整20分钟轮`lf-4e3eca7621`已通过，见[完整计时回执](full-life-acceptance.json)与[持久模型用量](full-life-known-usage.json)。真实自然到期后安全返家，状态completed；重启没有延长期限或重置40金币/一瓶已用额度。其准备、执行、回执和自动测试边界详见主题。

第一版限定比奇地图0上述范围；停止或到期返家后待命，需新一次明确生活授权才能再次独立出发。默认本地试玩只有Gateway和Actor运行器保持后台运行，真人离开视野或登出后阿洛才能继续活动。本证据不提高Crystal全局parity、Candidate100或Accepted状态；不证明外部真人留存、付款、分布式/1000CCU或原英雄系统1:1。
