# R16 比奇出生区静态地图

生产版在登录成功后的开门或选角阶段预取比奇出生区。静态文件取自现有 Crystal 地图接口，并与同一生产资源版本、本机严格资源模式生成的地图逐字节一致。文件名包含 SHA256，客户端核对字节、地图规范版本、资源版本及规范化区域。真实网关的角色落点仍须落在地图可玩及渲染范围内。其他区域或预取不可用时继续读现有地图接口。 [地图元数据](../../../apps/web/lib/generated/r16-entry-scene.json)

产物沿用比奇地图 `0`、规范请求中心 `(296,620)` 和 `56×72` 请求大小，实际场景视图为原接口的 `48×36`。完整地图含 6,819 个单元、957 个精灵和 57 个门单元。966 个独立贴图帧路径均出现在固定资源清单中，缺失计数为零。构建前执行 `node scripts/generate-r16-entry-scene.mjs --check`。刷新产物时可用同版本普通接口原始正文执行 `--from-response`，生成器先验证已审定的正文摘要和地图覆盖。 [构建与来源回执](local-browser.json)

## 隔离 Chrome 与 File Gateway

| 流程 | 实际结果 |
| --- | --- |
| 静态预取 | 网关创建的一级战士正常落在 `(288,616)`。登录回包后 14 毫秒发出静态请求，早于开始游戏点击约 2.54 秒。封锁出生区动态地址后该地址零请求，约 1.10 秒内从进城回包到可玩首帧 |
| 摘要错误 | 提供同长度的 HTTP 200 错误文件。客户端只用一次动态地图请求完成进城，实际动态正文与可信静态文件逐字节一致 |
| 旧角色 | 原存档在 `(342,244)`，按自己的规范区域读取动态地图，落点和地图范围与存档一致 |

三条流程均实际按右方向键移动一格，点击宽屏黑边、确认退出，收到注销回包并读回落盘位置。原始 File 存档的哈希保持一致。64 项定向测试、68 项发布检查及生产构建和 TypeScript 通过。 [本机浏览器回执](local-browser.json) · [出生区可玩画面](first-playable.png)

## 正式发布与复测

正式域名和 `/version` 均已读回 `d3e9ebfa6b7f6dc5cb0f86fb64553603d60c5965`。发布流程分别校验了候选与公网静态文件的字节摘要。新的普通 Chrome 简中、繁中各一次出码、待确认及正常取消，二维码图像与官方钱包地址匹配。 [候选构建](https://github.com/Zombieliu/mir2/actions/runs/42872351879) · [正式发布](https://github.com/Zombieliu/mir2/actions/runs/42873694552) · [公网回执](public-release.json)

首轮官方 Testnet 钱包签名回放进入比奇 `(288,616)`。第一次预取在响应头后只收到 46,864 字节，到总期限后取消。选角阶段再次请求同一静态文件，在 293 毫秒内读完 458,475 字节。客户端按固定摘要校验后安装出生地图，进城回包约 3.26 秒出现可操作画面，同区域动态地图请求为零。脚本把中断和完成的两个 HTTP 200 都计入待检查响应，未继续发移动输入。正常退出回到选角。 [首轮网络与首帧](public-release.json)

第二轮以新的普通 Chrome 和官方 Testnet 钱包独立回放。静态文件只有一次请求，在 531 毫秒内下载完成。探针从完成的 CDP 请求重新计算摘要，客户端安装确切出生区，同区域动态地图请求仍为零。进城回包后约 3.34 秒开放操作。按一次右方向键，网关 `UserLocation` 确认 `(289,616)`，镜头同步，正常注销回选角。 [第二轮签名与移动](public-release.json)

第二轮地砖画面检查在 22 秒窗口内未通过。探针看到 243 个可见地砖元素，完成加载数为零，独立地图图集画布未显示。该窗口内 WebGPU WASM 正文尚未收齐。这里的可操作时间是客户端开放输入的时间，完整画面需单列验收。匿名 HTTPS 独立读取出生点附近四个地砖文件，正式站与固定 CDN 都返回有效且同摘要的 PNG。下一步在已登录会话记录地砖实际请求、加载或错误及舞台像素。 [渲染观测与匿名素材回执](public-release.json)
