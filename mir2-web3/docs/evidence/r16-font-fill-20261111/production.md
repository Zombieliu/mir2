## 未通过与性能边界

整轮 `passed=false`，失败码 **`PUBLIC_VISUAL_PACK_BODY_NOT_OBSERVED:entry-player-male`**。男性人物包第一次返回 200，收到 49,152 字节后约 29.9 秒中止；第二次约 20 秒中止，均为 `net::ERR_ABORTED`。发布探针曾完整读到该包 289,851 字节并核对哈希，只能证明探针成功，不能替代游戏浏览器的读取。共用任务窗截图仍可见资源缓存失败提示。

从点击 Start 算起，本次约 **49.9 秒**才可操作，共用 HUD 约 **295.8 秒**才观察到可用。繁中字库的 Worker 正文传输约 104.9 秒，其他字体和运行包也较晚完成。147 毫秒只是这一次首步的结果，不取消此前 23.1 秒等长尾失败。控制台还记录资源 404、503 和移动摇杆动态模块超时，未宣告清零。

实际 Worker 已检测到字库共享代码，最终保留池为 0；捕获的 Worker ResourceTiming 含一次完成的繁中字库正文。Native 的繁中读取发生在 CSS 完成之后，约 90 毫秒完成，属于缓存读取。这次公网没有重现两消费者正文重叠，不用它替代前置真实浏览器慢传输的 **2→1 下载**对照，也不将所捕获的单个 Worker 条目写成全字体网络记录。

本轮有完整、无数据丢失的 61,494 字节 `blink.user_timing` 标记 trace；它不是完整 CPU profile。独立 PerformanceObserver 全程最长任务为 200 毫秒。Vercel 指定部署 11:45–12:05 UTC 的 error/fatal 查询无匹配服务端日志，不代表浏览器、Gateway 或素材服务没有错误。
