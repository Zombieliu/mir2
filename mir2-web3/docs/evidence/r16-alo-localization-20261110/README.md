# Web 阿洛窗口语言复测

Web 阿洛面板读取游戏当前语言，并复用 Windows R16 语言目录的字体和文字方向。保留 1024×768 游戏逻辑舞台、744×644 面板和六页布局。翻译固定界面文字、已知状态和回执。角色名、回忆正文、私密指令和运行器叙述保留原文。

| 覆盖 | 语言 | 词条 |
| --- | --- | --- |
| 全部固定文案 | 简体中文、繁體中文、English、العربية | 各 216／216 |
| 入口、操作、状态与授权确认 | Português (Brasil)、Русский、हिन्दी、Bahasa Indonesia、Tiếng Việt、ไทย | 各 204／216 |

后六种语言的 12 个英文回退项涉及教学及指令说明、导出说明、自主生活金币说明和费用明细。固定授权确认明确同一上限、目标和期限。运行器提供的事件类型、结果和采购步骤标识继续原样显示。

普通 Chrome 通过隔离 `/game` 用英文、简中、阿语分别登录同一角色。英文场完成固定教学，服务返回 v2。新的简中与阿语会话读到同一条回忆。三种语言都从窗口检查补给权限和自主生活页，再正常退出。阿语窗口使用 RTL，输入框按文本方向处理。测试使用规则运行器，三次的模型调用计数均为零。

两轮浏览器量测记录了边缘和两行按钮溢出。修正文字行高和对齐后，三种语言共 24 个窗口样本无溢出。用本机 Windows R16 字体测量十种语言的 270 个固定按钮标签和 30 段授权文字，均能放入原尺寸。64 项 Node 测试和完整 Web TypeScript 检查通过。
