# R16 晚到静态地图与任务窗

基于 ea4f82d86f 的本地生产候选 ea4f82d86fe8-r16-scenerace-592d194a。旧静态地图使用 12 秒总期限，而地砖和人物已分段计时；2.5 秒预热等待结束后，普通路径失败不会再采用随后完成的静态包。实际公网负例见[上一发布](../r16-graduation-release-20261111/README.md)。

静态地图现在复用受字节上限、SHA256、响应头期限、正文闲置和总期限保护的读取器。先保留短预热，再竞争静态与普通地图；普通失败仍等独立静态结果，合法普通地图先完成则直接使用。静态胜出取消多余普通请求。切图、换会话或退出的 owner 取消会拒绝迟到写入；错误地图、越界和校验失败保持拒绝，424 等普通错误在两路均失败时保留。

66 项定向及相邻检查和生产/TypeScript 构建通过。复用 27 个已校验产物，Rust/运行包未重编。Node 用实际 Page 效果测试普通路失败后晚到静态安装，并覆盖取消、错误、已有地图和版本隔离。
