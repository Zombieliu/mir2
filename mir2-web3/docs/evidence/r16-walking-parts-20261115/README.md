每块独立校验字节和SHA，按清单顺序合并后再次验证原完整764,724字节与 `41fcaae2757ad0351da2e3840bf54008952b5c2714441530bb64c21f5c9fd64f`。数据未完整、错序、缺PNG、坏摘要均不能发布。正常主JSON成功时不请求这些备用块。

主中文字体在运行包有效响应头到达时开始读取；如果响应头仍未到达，则借用现有8秒准入期限启动一次。六字体完整预热仍在最终运行包成功后执行。退出、跳过Native、复用已启动运行器和后端回退不产生额外主字体请求，不改变Native的真实就绪条件。
