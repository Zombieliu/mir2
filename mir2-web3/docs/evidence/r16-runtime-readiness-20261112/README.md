## 修复

原实现只向二进制 fetch 发送取消信号：若 WASM 已编译完成而脚本导入仍悬而未决，初始化 Promise 不会退出。现在下载阶段与原 120 秒取消预算竞速；过期尝试不会因迟到脚本继续等待 Canvas 或初始化。脚本加载失败会释放该版本的失败 Promise，下一次可重新尝试。

页面原先把任何初始化失败都永久锁到整页刷新。现在只允许尚未尝试启动 Bevy App 的网络错误在下一次普通进入时重试；已经尝试启动实例、能力不匹配或 GPU 初始化错误仍受原单次启动保护。没有自动循环重试、整页跳转或新的服务端指令。
