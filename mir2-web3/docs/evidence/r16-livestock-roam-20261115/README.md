# 共享 Zone 中立家畜空闲漫游

2026-11-15，R16 源码 `dca152cd15fc5ab9782fd28f2247d89c5faa9e6a` 已提交推送。本轮补齐无主、中立 AI1/2 家畜的服务器空闲动作。前端沿用已独立构建的 `9337f00a36` 并行完整包候选；默认英文与共享 WebGL2 繁体的两场完整本地流程均通过。**未发布公网，不代表完整 Crystal ProcessRoam 或整体 1:1 已完成。**

## 实现与边界

参考固定 Crystal `92b4ce4ab488b11e65f63d3ad22de2e1f25ec08d` 的 `MonsterObject.ProcessRoam`、`CheckAlone`、`CanMove`、`Walk` 和 `Deer`：没有目标时，每 1000 ms 尝试一次 1/10 概率；命中后 1/3 随机转向、2/3 沿当前方向走一格。独立保存 RoamTime 和移动期限，移动期间仍消耗到期的漫游抽样；被攻击后不提前结束当前行走，也不凭空增加一次空闲思考等待。每 3000 ms 检查 32 格内玩家，空图不补历史动作。

实际位置、静态碰撞、玩家／怪物占位、ObjectMonster 留存与 AOI 广播均由共享 Zone 单一写者更新。死亡、控制、不可见及所有权边界继续限制行动；守卫、训练物、宠物、其他 AI 家族不交给这条漫游路径。未开启个人会话怪物更新，也未用客户端动画制造移动。

随机状态和期限放在可选 `idle_roam` 中，缺字段旧检查点仍可读。首次空闲更新初始化一次 0–999 ms 抖动，使用独立可回放随机流，不承诺原 System.Random 的逐次序列相同。普通检查点会校验完整性，篡改随机状态被拒绝。冷恢复不会恢复旧在线奖励领取者的权限。其他物种、巡逻 Route、配置扩展及全局 ProcessRoam 资格仍开放。[六份源码输入](source-binding.json)。
