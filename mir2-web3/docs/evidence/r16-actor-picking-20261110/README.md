## 栗树与奥玛

Windows 在鼠标所在格周围两格内按行和格从右下向左上选取角色，同格允许命中。跨格取当前身体帧的单个非透明像素。活体优先，同格采用反向入场顺序，像素暂不可读取时只给 NPC 实际身体边界兜底。Web 的共享画布与 DOM 路径复用该判断。原有可见姓名和掉落标签保留操作入口。 [Windows 取样代码](../../../apps/game-client/platform-windows/src/atlas.rs#L1996)

天然奥玛走到栗树后。旧版在浏览器像素 `(903,432)`、地图格 `(259,405)` 命中树的透明矩形，选中栗树。修复版 WebGPU 在同一屏幕像素，WebGL2 在同一格的另一个合格像素，各点一次就选中奥玛。点下时采样确认两端的树帧在该处周围两像素均透明，奥玛帧为实色。两路收到同一个奥玛的 `ObjectStruck`，注销档读回 `(256,404)`。重叠点两帧都为实色时，WebGPU 仍选中前景栗树并正常保存。实际 Web 帧的完整 RGBA 与冻结 Crystal 原始库逐字节相同。 [旧版](old-transparent-click.png) · [透明处](transparent-click.png) · [实色处](solid-click.png)

这三次浏览器复测的角色身体由实际加载的 DOM 图像提供。已驻留多页图集与预建图集裁剪通过定向测试。整张世界由 GPU 图集绘制时的真实点击仍待复验。

## 经典右键短按

普通左键先走一步，服务器确认到 `(298,269)`，再在同一个 600 毫秒动作间隔内右键短按。旧 WebGPU 与 WebGL2 在松手后约 151 和 211 毫秒各补发了一步。候选两路在松手后 1.65 秒内均未再发移动，原位置正常写入存档。开启新版移动后，在同样间隔内点击目标仍能收到三次移动回执，抵达并保存 `(294,266)`。空闲经典短按的单步在同一 Page 修复上另验。 [冷却短按后的落点](busy-short-tap.png)

## 验收边界

本轮 241 项 Web 定向测试和 Stage5 的 520 组测试通过。冻结 Windows 的 19 项悬停相关测试通过。公网 `a23cc382` 在新 Chrome 简中和繁中首次点击约 7.5 和 8.5 秒出码，查询返回待确认，可正常取消。后续独立冷启动曾在 45 秒内未显示登录入口。实体手机默认网络进城、冷加载性能和正式发布继续单列。 [公网入口](https://numeron.obelisk.build/game)
