# Web 大火球与灵魂火符的 R16 客户端复测

参考为分支 `codex/windows-player-journey` 的 Windows VIS-02 夹具和效果实现 `ca1028b684`，Crystal 源码固定于 `92b4ce4ab`。浏览器使用同一隔离 File Gateway 和三职业毕业记录里的法师、道士 30 级档副本。用普通登录、选角、走跑、F11 绑键、悬停和 Ctrl+F1 施放，正常注销后用新浏览器会话重进核对熟练度。实际文件哈希、阶段采样、HTTP 音效状态、角色动作、资源用量和失败摘要见 [验证记录](verification.json)。

| 项目 | 大火球 | 灵魂火符 |
| --- | --- | --- |
| R16 施法 | `Magic/400–409`，600 ms | 600 ms，施法音效，无施法位图 |
| R16 飞行 | 16 个方向，每个 6 帧，`410 + 10 × 方向` | 16 个方向，每个 3 帧，`1160 + 10 × 方向` |
| R16 命中 | `Magic/570–579`，600 ms | `Magic/1360–1369`，600 ms |
| 旧 Web 七格样本 | 施法与飞行同批出现，飞行取方向 0，只有 `M34-0` 播放 | 立即飞行且取方向 0，三段音效均未播放 |
| 候选七格样本 | 默认 WebGPU 启动，观察到施法动作、方向 9 的飞行和正确命中帧 | WebGL2-shared 启动，观察到方向 9 的飞行和正确命中帧，无施法位图或替代闪光 |
| 浏览器音效采样 | `M34-0/1/2` 各一次，0／614／1006 ms | `M64-0/1/2` 各一次，0／751／1090 ms |

两种技能均以 `ObjectMagic` 为起点。旧兼容发射包不会另生成一发。客户端在施法 600 ms 后发射，飞行以每格 50 ms 计算，固定发射方向并跟踪目标位置。命中位图加色叠加，位于地形和角色位图之后。以窗口定时器、DOM 采样和播放回调观察的时刻存在调度延迟，表内数值相对该次施法音效。六段源 WAV 的字节和 SHA-256 与 Windows 参考相同，浏览器六个媒体响应均为 206，`play()` 均成功。

七格野鸡样本收到死亡包后仍处于倒地过程，命中效果保留。城外活鹿另用前一候选源复测。法师的目标在发射前从 (250,320) 走到 (251,321)，从新方向发射。道士的目标在发射后从 (235,326) 走到 (236,325)，飞行保留方向 11，命中绘于新格。两只鹿均存活，两次重新登录读回熟练度。固定时间测试额外覆盖 16 方向、待发、飞行中消失、仅飞向包内坐标、倒地过程可命中、尸体状态抑制命中以及去除过期阶段。

验了技能资源导出、音效导出和字节、场景效果、动作与死亡状态、开局对象边界、23 项有限资源清单检查及 Web 类型检查。重新生成外部 `common` 资源闭包并校验物理文件，共 21,056 项、281,160,211 字节。另验最终发行包及其资源路径。

普通 Web 渲染仍需对比 Windows 窗口。强制独立 WebGL2 首轮未达到输入就绪，随后 WebGL2-shared 路径通过飞行、命中和音效。移动后接施法的一轮仍采到走跑姿势。普通走跑停稳 1.1 秒后的重试采到 `spell` 姿势，三段音效与重登仍通过。并行法师探针一次在请求后 761 ms 收到伤害，低于上一轮浏览器容差，原样保留。独立重试完成同档读回。服务器包可早于浏览器本地飞行或命中特效，仍需测两端在相同负载下的伤害数字和连续动作时序。此次证据属于本机候选。
