# R16 Web 点怪追击与右键走位

2026-11-10 基于 `2e205376e0` 对照已提交的 Windows R16。Web 候选是本机生产构建 `Q1uIxiLliOmrj0ODGy9fD`，使用重新构建并校验的 `bevy-48c1f266331da4cb` 和同一个普通 File Gateway。所有实测使用真实键鼠、天然怪物和正常注销存档的隔离副本。 [源码、构建和回包校验](receipt.json)

## 逐格追击

相同 30 级战士在比奇 `(298, 269)` 单击五格外的活鸡一次，随后不再输入。旧版途中发出两格 Run。Windows R16 锁定目标时逐格走，每一步重新核对可达的相邻格。Web 修复后在普通 WebGPU、开背包的共享 WebGL2 上各收到四次单格 Walk 回执，约 3.3 秒命中并收到该怪死亡回包。死亡后约 1.9 秒内没有再发送移动或攻击。两次正常退出均保存至 `(296, 273)`。 [开背包追击命中画面](ordinary-chase-hit.png)

Web 每次只排入一个追击步，发送前检查原目标和坐标。重新选怪会丢弃旧的未发路线，已发出的移动继续等待自己的回执。共享控制器在可达相邻格暂时为空时保留目标，路通后能在没有重选的情况下继续。堵路、位置更新与清除由 Rust 定向测试覆盖。现场两路中的鸡未移动，实际移动目标与临时占位另验。

## 右键走位

旧版右键点在鸡图像上会发起攻击，点比奇告示牌图像会打开对话。修复后用相同物理像素重测，屏幕像素下的地格空闲可行。对鸡与告示牌的右键只发移动，服务器确认新位置，两个档都正常退出。左键选择与界面拦截有定向回归。鸡图像的实测中，松开右键后仍发出一条已排队的 Run，经典模式的松手时序单列继续验证。 [告示牌右键后的画面](right-click-npc-overlay.png)
