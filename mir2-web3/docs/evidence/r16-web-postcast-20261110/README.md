## 比奇岸边的真实抛竿

隔离 File 副本在 `crystal_full` 内容档购买鱼竿、鱼钩、鱼饵和绕线轮，用 Windows 传输兼容的普通装备包完成装配。正常退出后，同一档在 `platinum_fiveclass` 的最终本机生产 WebGPU 构建重登。道士对天然野怪正常施放灵魂火符，走回比奇岸边，最后一步向左下走到 `(342,244)`。实际左键点击三格外 `(339,247)` 水面。站姿和方向来自已提交的轻量 WASM 读取。

最后一步确认后直接发送一次 `fishingCast`，服务器发送 `FishingUpdate` 确认进入钓鱼。鱼饵 3→2，鱼钩 8000→7999，鱼竿 10000→9999。正常退出后，File 保存读回位置、朝向、鱼饵 2 和鱼竿耐久 9999。共享画布按同一世界指针及最新提交的布局复核，前景窗口、其他指针及改变后的画布仍拦截。 [物理点击、服务器顺序及读回](fishing-verification.json) · [岸边截图](fishing-shore.png)
