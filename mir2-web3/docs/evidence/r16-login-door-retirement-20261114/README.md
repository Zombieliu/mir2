## 发现与修复

[当前正式站的完整静态对照](../r16-world-snapshot-gzip-20261114/candidate/README.md)
观测到开门阶段的多张约 2.5MB 大图，进城后仍下载，最长持续 175435ms。
该轮运行包正文及 Native HUD 都超过原 120 秒门槛。请求重叠是事实，性能收益尚须对照。

`R16LoginDoor` 将预载并发设为 1，组件离场时撤销自己的队列。预载器共享一个绝对截止
时间，临近截止不再启动不足最小尝试预算的新图或备用源。调用者可通过 `aborted` 区分
撤销与普通加载；原 `status` 类型保持兼容。19 张素材、100ms 播放节奏及 30 秒开门预算保持原值。

共享图片和 Worker 缓存仍可完成正在使用的正文：撤销只退休本次队列及后续备用尝试。
它不会中断其他场景的同图读取，也不清空已有缓存。因此，最多一张已开始的开门图仍可能
在离场后完成，不能写成“所有旧网络请求都会立刻中止”。
