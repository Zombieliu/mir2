# R16 阿洛自主生活 Web 验收

Windows R16 的第六页按服务器观察显示生活阶段、购药核对、原授权剩余时间和阿洛自己的资源。Web 补齐该页与底部「确认恢复原生活授权」。账本与协议沿用共享实现；未知金额和过期库存不会显示为零，模型计划不会当作实际战绩。

Chrome 在隔离 File 世界通过普通登录、选角和进比奇。30 分钟只打开预览再取消，未发授权。确认 20 分钟后有一条真实授权；服务器激活后正常停止运行器，再用原 SQLite 启动新进程。浏览器显示暂停，恢复预览取消时仍无请求。再次确认后只发一次 `resumeLife`，请求携带原授权引用和当前培养版本。服务器重新激活同一授权，到期时间、50 金币上限、最多一瓶、实际扣款与预留均保持。停止后读回 `cancelled`，正常注销得到一条回执，三项隔离服务已退出。
