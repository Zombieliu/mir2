## 公网实际体验

新建普通 headless Chrome，通过正式页面生成真实二维码。官方手机尺寸 Testnet PWA
用虚拟 passkey 完成一次登录授权，兑换后正常选角、最多创建一个 QA 角色并进比奇。
仅登录签名，无资金操作；此项不等同于实体手机相机扫描。网络没有 DNS / TLS / HTTP
协议替换或响应模拟。
