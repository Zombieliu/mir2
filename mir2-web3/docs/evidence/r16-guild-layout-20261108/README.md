# R16 公会窗口与职级交互

Windows 与 Web 共用 `r16-guild-layout.json` 的590×432窗口、左右独立页签、职级控件和资源坐标。Web 改为单选编辑，支持拖动、下拉滚动、Enter、IME、Escape与确认框；全局 capture 为明确的局部键盘拥有者让路。

普通 type4 新建以真实自身 status6 和完整结构回读确认；type3改名及type5单项权限继续按原权威回执处理。职级重编号会重挂编辑身份；普通改名增量保留脏草稿。展示权限与动作权限分开：有仓库权限时入口可见，物品动作仍等待真实数据。

统计数字来自 GuildStatus，独立保留于物理会话展示缓存，不因精简世界快照丢失；未知显示“—”。两后端已核对真实等级1、人数3/上限5、经验0/700000。只读仓库刷新收到112格列表，个人和公会资产摘要保持。

本轮各源快照、命令范围、截图与散列见 [verification.json](verification.json)。后续统计和仓库增量与此前职级变更流程分别取证，没有把旧结果重复当成新源完整验证。

五条新增系统短语进入共同十语词库；旧条目与别名逐值保持。Native 几何接入和本地化有限定代码检查，未运行新 Windows 窗口或分发新 EXE。

原语言菜单 driver 失败、一次未定因的编辑器消失均保留。当前成员/仓库/Buff全像素、原英雄、所有地图技能、Native跨端及最终真人 Accepted 仍未由本轮关闭。发布验证另行执行。
