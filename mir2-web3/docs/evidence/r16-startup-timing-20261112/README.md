## 诊断与验证

被动 CDP 同时观察页面与 Service Worker 的真实上游请求，不限速、不拦截、不改缓存或请求。脚本见 [observe-network.mjs](observe-network.mjs)，协议定义见 [Chrome Network](https://chromedevtools.github.io/devtools-protocol/tot/Network/)。Worker 会完整收取字体正文后才交给页面，因此页面的“响应头等待”包含正文传输，不能直接归因于网络排队。

旧顺序的本次样本中，简中字库发送起点约 0.1 毫秒、上游首头约 343 毫秒，正文却用了 61.13 秒。该请求已经是 High 优先级、gzip 和边缘 HIT；这份样本支持正文传输慢，不能据此声称连接排队或压缩缺失。新顺序的独立样本正文约 23.02 秒；普通网络变化存在，不能把两次差值全部算作代码收益。
