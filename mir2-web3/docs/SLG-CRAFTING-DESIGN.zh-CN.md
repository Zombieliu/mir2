# 制作与加工系统设计

状态：设计草案 v0.2。日期：2026 年 10 月 8 日。

本设计补充[种植 自由建造与行会领地设计](SLG-PRODUCTION-TERRITORY-DESIGN.zh-CN.md)。统一制作与加工属于拟新增玩法；原版武器精炼按其现有独立流程保留，不能把精炼界面或服务端代码当作本系统已经可玩。

## 1 生产链与玩家分工

生产链为：正常玩法取得原料 → 在对应设施加工 → 形成补给或建材 → 自用、交易或入行会仓库 → 在战斗和建设中消耗。每个配方必须具有正常玩家可达到的原料来源和具体用途，不用管理员发物品证明生产链已闭合。

| 原料来源 | 加工方向 | 消耗出口 |
| --- | --- | --- |
| 种植药草与谷物 | 常规补给、面粉 | 三职业用药，普通与进阶食品 |
| 已上线挖矿的指定普通矿石 | 与采集木炭组合加工为金属连接件 | 木构件、结构建材、后续领地升级 |
| 拟新增木材、石料、纤维采集 | 木板、木炭、建材石、捆扎绳 | 与矿产组成建筑部件，多种生产设施共用 |
| 种植、采集和钓鱼 | 面粉、野果、香草与鱼组合 | 普通口粮和进阶食品 |
| 拟新增专用盐矿 | 与木炭加工为食用盐 | 与种植、采集、钓鱼食材组成进阶食品 |
| 打怪取得材料 | 后续装备加工辅料 | 原版允许的精炼、修理或新增非毕业装备配方 |

玩家可以只打怪后购买补给，也可以专注生产或运输。加工不成为新手主线或攻沙资格的强制步骤，不提供无限角色经验。稀有技能书、毕业装备和 Boss 专属掉落保留打怪获取价值。

### 1.1 组合原则

生产采用原料、加工材料、部件、成品四层。加工材料可以进入多个配方，成品可以需要多个来源；建设消耗加工后的部件，不能把所有建筑都写成直接扣原木和原矿。组合关系用版本化目录表达，不按职业或玩法硬编码单独链条。

首期只开放少量、可逐步理解的组合。农田可以直接消耗木材，基础补给包仍沿用药草与谷物；仓库、加工台及进阶食品引入两到三层加工。玩家可以生产其中一环、买卖中间材料或购买成品，不要求每个人亲自采齐全部来源。

### 1.2 材料来源与复用

木材加工成木板或木炭，纤维加工成捆扎绳。普通矿石与木炭加工为金属连接件，石料与木炭加工为建材石。木板、连接件、捆扎绳组合成木构件；木板、建材石、连接件、捆扎绳组合成结构建材。木构件与结构建材进入真实建筑施工及升级用料。

谷物加工成面粉，面粉与采集野果制作普通食物。进阶鱼饭再组合钓鱼取得的鱼、采集香草和食用盐。食用盐来自专门的岩盐加工配方，普通金属矿、黑铁、金矿及矿物粉末不能代替食品成分。专用盐矿尚未实现，关联食品随来源一起开放。

木炭同时用于矿石加工、建材加工和岩盐加工；木板用于木构件与结构建材；面粉用于两档食品。每项中间材料都要有明确用途。基础配方保留直接购买替代途径；稀缺节点的刷新、供应量和每次消耗须一起测算，避免所有成品被同一种资源卡死。

基础补给包沿用前文药草 10、谷物 5 的配方示例。拟包含小 HP/MP 药品各 5；具体模板、效果和售价按现有普通药品目录核定，未核定前不开放配方。包的打开与扣包、入包也必须使用普通物品消费的持久规则。

建材石不默认吞掉黑铁、金矿或高纯度精炼材料。普通矿石白名单由目录定义，玩家可查看将消耗的具体实例及纯度；背包、腰带、装备和保管中的物品遵循原有来源编码。未允许作为原料的装备和有附加属性的物品不会因为名称相似被消耗。

比奇和盟重的拟新增共用作坊先提供基础加工台、窑炉与厨房。新手无需先建私人加工台才能加工其建筑材料，避免“要加工台才能做建材、要建材才能建加工台”的循环。公共设施按角色保管生产任务，不让一个玩家占住全服唯一队列；NPC 位置和资源须正常入口验收后绑定。私人加工台首期只承担基础加工台配方；窑炉与厨房的私人建筑列入后续扩展。

实际开放按全链条件判定：原料正常可取得、所有中间配方可使用、设施可进入、物品目录已绑定、产出有实际用途。任一环尚未落地，其关联配方显示未开放原因；不能仅因为顶层按钮已有实现就宣称可制作。

第一版数量为每批 1–10 份，每台私人设施最多一批进行中。批量工期为单份时间乘数量，完成时整批成为待领取状态，离线继续计时。输入材料不足时显示每项“现有/需要”，不要求玩家尝试发送后才知道缺料。批量不是整条链自动生产；每一步加工仍独立扣料、产出和领取。

教学赠送的绑定种子产物保持绑定。任何绑定原料进入制作，其产出保持绑定；绑定产物不能借公共仓库或交易转成可交易物品。教学领取按账号记录一次，删除或新建角色不重置该领取记录。

## 3 制作流程与领取

选择设施 → 选择配方 → 选择数量 → 检查材料、金币、工期和产出 → 确认制作 → 离线或继续游戏 → 返回设施领取。

加工状态分为：可制作、请求处理中、生产中、待领取、已领取、已取消、结果不明。客户端显示剩余时间，服务器决定是否完成。生产中不可改写配方、数量或来源仓库。

开始时统一扣除本批投入并记录保管中的用料、配方版本和工费。完成后产物保存在任务记录中，不直接塞进已满背包。领取时先检查整批空间与重量，成功后产物入包并标记领取；容量不足则保持待领取，不能交付一部分后丢失余下产物。

未发送的制作预览可以免费取消。已开始生产的任务可取消，拟返还材料的 50%，向下取整，工费不退；已完成待领取任务不能取消。返还无处存放时保留任务并解释原因。取消、完工和领取须互斥提交，不能同时得到产物与退款。

加工台有生产中或待领取任务时不能拆除。界面关闭、离线、角色死亡和地图切换不自动取消生产。删除角色前退役该角色的设施访问并封存生产资产，原槽位的新角色不能取得旧任务；删除和资产恢复规则是正式开放的前置验收。

## 4 行会工坊

个人制作使用个人背包与金币，产出进入个人背包。行会制作使用公共仓库与授权公共预算，产出进入公共仓库；启动者不会自动获得领取成个人物品的权利。

启动行会生产、取消生产和领取公共物资是三个独立权限。建设授权不自动授予公共物资领取权限。成员离会或被踢后，已提交生产继续属于原领地，旧界面不能取消任务或领取产物。

每批记录配方、投入、启动者、设施、费用、提交时间、完成时间、产出和实际领取。捐献、公共加工和公共领取各自有回执，不能通过重复点击或断线重试复制物资。

第一版公共工坊最多一批生产，后续升级可增加明确的队列槽位。升级不得重算已经开始的配方成本或完成时间。战争保护期间暂停新建、升级和取消设施，既有生产继续；能否领取按战争模式的授权规则判定。

## 5 制作界面

庄园与领地管理增加“制作加工”入口。个人加工台显示配方、数量、材料清单、金币、工期、产出、当前任务以及领取/取消。界面必须明确当前来源是个人背包还是公共仓库。

地图上的加工台也可打开同一面板。未接近设施、设施未完成、权限不足或已有任务时，按钮说明具体原因；界面不能代替距离和权限校验。合成结果不明时保留原操作并查询，不换请求 ID 再扣一批材料。

配方可按“基础加工、建材、补给、食品”分类。未开放的配方显示其开放条件，不以可点击的确认按钮呈现。每项用料可查看来源：原料显示采集、种植、矿洞或钓鱼，中间材料跳到对应配方，并保留上一层成品与所需数量。缺料只引导正常获取，不免费补足或调试传送。

界面同时显示本次直接投入与展开到原料的生产计划。已有中间材料优先用于计划估算，缺少部分按上游批次向上取整，明确剩余产物和逐步工费；计划估算不代替实际背包实例检查，不把额外上游材料一起偷偷扣掉。选择上游配方时数量最多十份，更大需求提示分批，不能静默截断需求。

数量变化时一并更新总材料、总费用、总工期和产出数量。以文本显示现有/需要，不只用红绿颜色表达。滚轮只作用于当前配方列表；关闭制作面板不清掉服务器生产任务，退出制作输入后不保留旧攻击或奔跑指令。

交互草案的示例物资与演示时间仅用于查看流程，共用作坊的多种设施折合为单个示意加工点。正式界面仍须按实际设施、距离和开放条件校验；草案不证明真实扣料、背包容量、公共仓库并发或药品使用已实现。

## 6 持久提交与实现边界

沿用前文 Session、共享 Zone、经济服务和客户端的职责分工。任务保存投入的真实物品来源、不可变配方版本、数量、工费、服务器完成时间和产出规格；不保存仅靠翻译名称识别的物品。

开始制作由同一次持久提交确定物品扣除、金币扣除与任务创建。领取由同一次持久提交确定产物交付和任务退役。公共工坊还要核对当前行会身份、设施版本与仓库版本，不能从个人 Session 的旧快照恢复公共资产。

重复请求返回原回执，确定的提交前失败不扣料。结果不明时停止盲目重试，重连查询原操作。恢复后使用已保存的服务器完成时间，不因为停机而重启整批工期，也不因客户端修改时钟提前领取。

每个配方保存独立输入项、产出、设施、工费、工期、解锁条件和目录版本。材料组合只接受明确物品白名单；不能按翻译名称、宽泛“矿物”标签或同一材料重复占用多个槽位匹配。多种原料替代时使用显式配方版本并预览实际选中的物品，首期采用固定配方，不以高级矿物自动增加品质。

目录检查必须递归追溯正常原料和解锁条件，拒绝缺失材料、无生产来源及无限配方循环。回收、拆除和取消保存实际投入；拆除只返还当时消耗的木构件或结构建材，不递归拆回原料，也不同时返还部件和上游矿石。返还百分比不能因当前配方价格变化而多发。

配方系统新增独立模块及目录，武器升级/精炼保留原入口、原材料规则和保管流程。新的材料加工与原版精炼分别验收，不更改原版黑铁纯度、失败概率或检查领取过程来适配此界面。

## 7 实施与验收

先冻结两条首期闭环：种植 → 补给包 → 正常用药；采集木材、纤维、石料与挖矿 → 中间加工 → 组合建材 → 正常建造。普通食品在食品效果落地后接种植与野果采集；盐焗鱼饭最后接专用盐矿、香草与完整钓鱼。每次开放只增加少量配方；高阶装备、随机属性、配方书和熟练度留到基础系统稳定后。

| 验收场景 | 通过条件 |
| --- | --- |
| 一份与十份制作 | 总材料、总费用、工期和产出一致；不溢出数量 |
| 原料缺少或已移动 | 显示缺项，服务端拒绝旧实例，不部分扣料 |
| 多来源与中间材料 | 仓库、加工台用料能追到矿产与采集；进阶食品能追到种植、采集、钓鱼和专用盐矿 |
| 配方跳转与生产计划 | 缺少中间材料可查看上游；按现有库存、整批产量和余料计算；不自动扣整链材料 |
| 首座建筑 | 普通账号从共用作坊取得建材，能建首座仓库和加工台；没有设施循环依赖 |
| 来源尚未开放 | 专用盐矿、食品效果或任一上游缺失时，顶层成品正确关闭并解释原因 |
| 替代与返还 | 仅匹配白名单，原料不重复占用；取消/拆除只返直接投入，不能多层返还 |
| 稀有与绑定材料 | 默认保护高价值原料；绑定属性不被加工洗掉 |
| 断线与重启 | 原任务、费用、完成时间及回执恢复一致 |
| 两个会话同时领取 | 只交付一批，另一个得到原结果或已领取状态 |
| 背包/仓库已满 | 产物继续保存在任务中，不丢失、不重复领取 |
| 取消与完工竞争 | 仅一种结果提交，退款和产物不同时出现 |
| 离会或权限变更 | 旧界面和旧请求不取得公共产物 |
| 三职业与多语言 | 配方和药品能正常使用，长文本、数字与按钮完整可读 |

这些验收项目前均未关闭。离线界面草案与检查结果属于设计阶段；真实服务器、普通账号、签名交付及玩家验收完成后，才标记制作系统可玩。

## 8 原石鉴定与切割提案（2026-10-09）

状态：玩法建议，尚未实现，未加入可开放目录。本节回应新增“赌石”的想法，作为挖矿与加工之间的可选分支；具体概率、工费、产量和售价在首轮经济测算后冻结。

### 8.1 原料、加工与用途

正常矿区产出三档未鉴定原石。矿工可以出售整块原石，也可以带到比奇或盟重的鉴定、切割作坊，消耗金币及加工工具揭示并取得内容物。鉴定显示可信的品类线索和可能产出；玩家决定继续切割还是出售。线索、概率和工费须清楚展示，每块石头只取得一个固定结果。

| 结果方向 | 加工出口 | 后续消耗 |
| --- | --- | --- |
| 常见石料与边角料 | 接入建材石或装饰构件配方 | 仓库、加工台及领地设施建设 |
| 普通玉料、宝石原料 | 经同一加工目录切磨成材料 | 明确白名单的装备加工、基础镶嵌或设施配方 |
| 稀有原料 | 对应有限的高阶加工配方 | 与其他正常来源组合的进阶用途 |

普通结果也有正常消耗出口，稀有结果承担惊喜和交易价值。首期只接少量已有或明确落地的材料用途；不能因为设计了“玉料”名称就宣称其镶嵌、建筑效果或运行模板已经存在。收益测算同时考虑原石来源速度、每类概率、产量、工费、工具消耗、交易需求和NPC回收价，防止买石切割后卖回NPC形成无限利润。

### 8.2 结果与物品身份

原石生成时由服务器锁定内容、来源和结果表版本，跟随原石的不可复用身份保存；鉴定和切割只揭示原有内容。交易、仓库转移、角色重登、服务器重启和结果表更新均不能重新抽取。封存内容只保存在服务器权威状态，切割前的普通物品包不泄露结果或可推算结果的种子。

原石发行及锁定结果须具有可恢复的确定状态。切割使用原石真实实例、操作请求ID和库存版本，统一提交扣石、扣费、工具消耗、最终产物及回执；两个会话竞争只产生一次结果。空间不足保留原石或已确定的待领取产物，不能丢失、重复发放或允许重新抽取；模糊提交查原回执，不盲目重试。已有奖励箱的打开时随机选择和个人同步库存保护不等同于上述持久切割事务。

### 8.3 首期体验与验收

沿用侧栏管理布局显示原石、鉴定线索、工费、可能产出和处理状态。先用清楚的文字及简短揭示动画完成流程，再增加外观表现；面板输入不能遗留奔跑或攻击指令。任务可引导一次鉴定与切割，后续由玩家自行选择参与。
