## 方法与边界

- 下载驱动：Windows 自带 curl 8.21.0、Schannel 正常证书验证；禁用 curl 用户配置，`--noproxy *`，无跳转、无自动重试。仅移除新测试子进程的代理环境变量，未更改系统代理或安全设置。
- 下载限速 2,500,000 字节/秒（20Mbps）；安装、启动器及子游戏共同受 Windows Job 约束：4 个逻辑 CPU、8GiB 合计提交内存，禁止脱离 Job。记录实际成员与限制。
- 本机实际为 i9-13900KF、64GiB RAM、SSD、RTX 5070 Ti。Job 的提交内存限制不等于物理 8GiB 电脑；操作系统文件缓存未清空。每次冷测使用不存在的新下载和安装目录。
- 浏览器点击下载链路未验；本轮采用原生 Windows HTTPS 下载和 GUI 安装。界面截图、实际 Ready 回执及 Healthy 状态必须对应同一完整包与进程树。
- D0 在下载前记录，D1 包含实际完整哈希核验，向导等待、操作、首次启动、核验均计入总时间。失败运行保留原计时和原始证据。
