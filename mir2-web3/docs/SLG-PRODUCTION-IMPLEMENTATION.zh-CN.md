## P02a 个人经济事务

`SimulationSession` 新增服务器配置、持久角色身份启用、开工/领取/取消、原请求查询和个人订单查询方法。没有新增玩家 ClientPacket、NPC 脚本或网关路由。角色沿用已有随机持久 actor，不以名字或角色槽作为可复用身份，也不轮换已有购买者的 epoch。

- 从真实背包和快捷栏生成 UID、模板、数量、绑定及完整 ItemState 投入。装备和保管中的物品不作为原料；附加属性、镶嵌、租赁、封印等实例拒绝。矿石纯度独立于件数，普通矿石须有明确纯度上限，黑铁和金矿不能消费。
- 同一完整角色事务保存扣料、扣费、冻结配方订单及请求回执。严格核对完整存档和订单版本，旧会话不能用新存档里的不同背包执行旧计划。
- 领取和取消先检查整批合法格子及真实负重；容量不足保留未结束订单，既不发部分物品，也不提前消耗新 UID。当前交付使用独立新堆，不自动合并已有堆；这是保留原载体的保守容量规则，后续界面必须显示实际占格。
- 成品和拆分退款使用持久分配器的 Crafting 原因；每次发行前扫描锁定的完整账号存档与当前角色，包括其他角色装备、嵌套物品和历史投入，抬高 UID 下限。退款保留原载体及绑定，原投入 UID 只是来源，仍在背包的残堆不会复用编号。
- 确定提交后才更新 World 和生成成功物品包。相同请求重放只返回原回执，不重复发货。提交后的异常保留回执；模糊写盘结果沿用原账号权威的冻结机制，不能用新请求 ID 重扣，也不能仅重开缓存解除冻结。
- 普通保存和同会话恢复不能制造、改写或退回已提交订单；离线重登沿用冻结配方和完成时间，当前价格和开放条件变化不修改已付订单。

原 CargoGuard 下本轮实际 **123 项通过，0 失败/ignored**：规则19、新个人事务15、原购买30、存档59。测试使用真实 Crystal 物品载体和隔离 File 存档，覆盖背包/快捷栏、绑定成品、取消退款、重登、重复及冲突请求、双会话 CAS、整批容量/负重、普通矿石与黑铁保护、其他角色高 UID 装备、普通保存/恢复，以及写盘前失败、模糊发布和确定提交后的异常。全部原始记录见 [P02a 验证](generated/slg-production-p02-20261008/README.md)。

这不等于正常材料获取或多人实机制作验收。**P02b 尚未完成**：其他物品发行路径仍使用局部 UID，需要全部迁移到同一全服权威；Postgres 源与故障路径未跑；模糊发布后的显式协调仍是上线前提。正常目录继续禁用，隔离测试配方与材料别名不进入玩家配置。

## 已完成的基础代码

| 内容 | 当前行为 |
| --- | --- |
| 可组合配方 | 读取 v0.2 目录；检查材料、生产来源、循环、数值范围及唯一产出 |
| 全链开放条件 | 递归核对原料来源、上游设施、解锁条件和真实物品模板绑定；缺少一环就拒绝开工 |
| 缺料计划 | 优先计算现有中间材料，展开缺少的上游批次，显示原料缺口、余料、工费和顺序工期；不自动扣整条链 |
| 一至十份批量 | 校验 UID、数量、模板和可用实例；生成真实实例扣料计划，保留原始物品载体 |
| 离线工期 | 记录服务器开始/完成时间；恢复后沿用原时间，旧任务冻结成本、产量和配方内容 |
| 领取与取消 | 到期后生成整批交付计划；提前取消按每种直接投入总量返还一半并向下取整，工费不退 |
| 绑定材料 | 任一绑定投入使成品绑定；退款优先保留绑定投入的原始来源，不能返还成上游原矿 |
| 请求重试 | 同一角色和请求 ID 的完全相同请求返回旧结果；更改配方、数量或操作则拒绝 |
| 保存恢复 | 验证配方身份、内容摘要、任务身份、投入数量、状态历史和每台设施的未结束任务 |
| 容量边界 | 编码记录上限 16 MiB；开工前为未结束任务预留最大领取/取消回执空间；历史记录不静默丢弃 |

这里的“扣料计划”和“交付计划”是交给真实经济事务的方案。返回方案不表示已经扣款、保存成功或发货。账本版本和背包版本必须一起核对，物品、金币、任务与回执必须一起持久提交，之后才能更新 World 和发送成功包。

## 后续落地顺序

1. 补齐个人经济上线条件：已完成上述受控事务接线；继续统一全部物品发行者的 UID 权威，验证 Postgres 源和故障路径，完成模糊提交的显式协调及正常网络路由。不能把本适配器接入分配器等同于全服发行迁移。
2. 正常来源：逐项加入真实木材、纤维、石料、作物及材料目录，接采集和种植；保留普通矿石白名单，保护黑铁、金矿、高纯度及精炼物品。新符号 ID 不能直接当游戏物品。
3. 共用作坊与界面：比奇、盟重的基础加工台、窑炉、厨房；检查位置、距离、当前操作权限，提供材料来源、缺料、工期、领取和取消显示。
4. 首个闭环：材料 → 中间加工 → 组合建材 → 实际建筑；种植 → 药品包 → 原版用药。随后接食品效果、正常钓鱼和专用盐矿。
5. 行会工坊：领地持有任务，使用共享仓库与预算事务，并独立检查启动、取消、领取权限；不能借个人 Session 保存公共资产。历史归档须保留重放与资产保管，避免长期生产达到记录上限。
6. 联网验收：普通角色获取材料、生产、离线重登、领取、满包、两个会话争抢、取消/完工竞争、权限变化与三职业、多语言界面。通过后才开启相关配方并发布可玩版本。
