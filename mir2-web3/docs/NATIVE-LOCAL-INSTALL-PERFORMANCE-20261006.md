# Windows 本地安装耗时修复

用户报告来自本开发电脑 D:/Mir2Invite。旧版已完成文件安装：解压7分53秒、
暂存7分40秒、准备9分40秒、正式写入38分57秒。资源包传输和压缩校验约46秒
是嵌套计时差，不能当作纯网络独立计时。瓶颈在本地小文件操作。

新版更新器在取得确切游戏文件的独占写句柄后进行完整进程和路径核对，随后
持续持有句柄，Windows 因此拒绝游戏中途启动、改名或替换。每次操作仍验证
这个实际持有的句柄；没有缓存“游戏未运行”的结论。句柄不写入、不截断，
无法取得句柄时保留逐文件即时进程检查和串行写入。
首次安装在日志授予权限后先替换已验证的 EXE，元数据和指针仍最后更新。
直接原子替换已校验、已落盘的同卷暂存文件，减少重复复制；恢复继续复制备份。
小文件解压缓存、暂存、提交前备份/验证及互不依赖的资源替换最多四路并行，
EXE 和最终元数据/指针仍串行。界面、下载源和取消判断
仍在调用线程；取消或失败先汇合所有写入者再返回。相同内容不并发争写缓存，
每个重复文件体仍独立校验，大文件继续流式处理。日志、落盘和首次启动回滚保留。
