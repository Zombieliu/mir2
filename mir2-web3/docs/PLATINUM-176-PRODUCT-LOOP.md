# 白金 1.76 完整产品循环

> 状态：Product Spec v0.1
>
> 目标：在 `mir2-web3` 现有 Crystal 数据与运行框架上，交付可验证的经典三职业 1–50 级成长、经济、Boss、PK、行会与沙巴克循环。
>
> 验收边界：本期必须证明三职业都能从 1 级自然成长到 50 级；50 级不是世界观硬上限，但 50 级以上不属于本期承诺。

## 1. 产品定义

### 1.1 一句话

一个没有付费数值捷径、所有力量都来自玛法世界掉落和玩家协作竞争的经典 1.76 时长服。

### 1.2 目标玩家

- 玩过早期《热血传奇》，重视稀缺装备、自由交易、行会关系和地图记忆的回流玩家。
- 没经历过端游黄金年代，但愿意接受高风险、高摩擦、强社交长期成长的新玩家。
- 不面向追求自动寻路、任务直升、日常清单和短周期毕业的用户。

### 1.3 核心承诺

1. **三职业**：只开放战士、法师、道士。
2. **无数值商城**：不出售经验、金币、装备、技能书、传送优势或掉率。
3. **世界产出**：核心物品由怪物、Boss、采矿、屠宰和玩家交易产生。
4. **自由经济**：绝大多数物品可交易，极品和技能书保有长期价值。
5. **风险成立**：死亡、耐久、补给、抢图和PK都必须产生真实决策。
6. **40级后不毕业**：等级放缓，目标转为装备、Boss、行会、沙巴克和声望。

### 1.4 明确排除

- 英雄、内功、心法、经脉、转生。
- 刺客、弓手及其装备和技能。
- 幻境、魔龙城及 1.76 之后的主成长系统。
- 元宝商城、抽奖、累充、战令、经验礼包。
- 自动战斗、离线挂机收益、任务一键传送。
- 全服拍卖行；首发只保留面对面交易和摆摊/寄售的经典形态。

## 2. 版本策略：Profile，而不是删数据

现有导入数据来自 Crystal DB v117，内容远大于白金 1.76。不得直接修改或删除原始 manifest；新增一个可切换的内容档案：

```text
content_profiles/
  crystal_full/
  platinum_176/
    realm_rules
    experience_curve
    map_whitelist
    map_aliases
    monster_whitelist
    monster_tuning
    item_whitelist
    item_tuning
    skill_unlocks
    drop_overrides
    npc_overrides
    boss_schedule
    economy_targets
```

运行时只消费编译后的 `platinum_176_bundle`。这样可以：

- 保留 Crystal 全量数据作为事实来源。
- 对外只暴露 1.76 内容。
- 用同一套代码运行开发服、全量 Crystal 服和白金服。
- 让每次掉率、经验、地图和技能调整都可审计、可回滚。

## 3. 四层循环

### 3.1 30秒战斗循环

发现目标 → 判断数量和风险 → 走位/拉怪/施法 → 消耗 HP/MP/毒符/耐久 → 击杀 → 拾取金币、材料、装备或技能书 → 决定继续还是撤退。

必须成立的体验：

- 普通怪不是木桩；职业需要不同处理方式。
- 补给和耐久会迫使玩家回城，但不应频繁打断前 7 级教学。
- 地面掉落清晰、可争夺、可被其他玩家看到。
- 稀有掉落必须产生“停一下确认是什么”的情绪峰值。

### 3.2 20–60分钟单次会话循环

选图与补给 → 赶路 → 刷怪/争点 → 背包或药水接近极限 → 回城卖杂物、修理、补药 → 学技能/换装备/交易 → 再出发。

单次会话必须至少给出一种进展：

- 经验条可见推进。
- 金币净增加或补给效率改善。
- 获得技能书、装备、材料或交易机会。
- 认识一个玩家、加入临时队伍或与竞争者发生冲突。

### 3.3 等级段循环

每个等级段都由五个要素闭合：

1. 新地图或更深层。
2. 新怪物组合。
3. 新技能或战术。
4. 一次可感知的装备替换。
5. 新的社交/竞争压力。

### 3.4 长期终局循环

40级后以“等级缓慢增长 + 装备稀缺 + Boss争夺 + 行会战争”为主：

刷普通怪维持经济 → 组织Boss队 → 获得或交易稀有装备 → 扩大行会战力 → 争夺地图与沙巴克 → 消耗金币和物资 → 再回到世界产出。

## 4. 1–50级成长路线

时间目标以普通熟练玩家、1倍经验、无外部资助为基准。正式数值必须通过三职业自动加速跑和真人测试校准，不能只靠表格推算。

### 4.1 地图开放原则

- 不做硬性的“等级不足禁止进入”，经典地图通过距离、怪强度、补给和死亡风险软门槛控制。
- 新手保护地图禁止高等级恶意清场；15级后进入开放风险区。
- 洞穴入口、补给点和回城路径必须形成可记忆的地理关系。
- 传送NPC只承担跨大区或必要回程，不替代步行和地图控制价值。

### 4.2 每段毕业条件

等级不是唯一条件。进入下一段前，系统验收应检查：

- 至少一件该阶段武器或衣服。
- 至少一个该阶段核心技能已学习。
- 有能力承担下一地图一次完整补给循环。
- 金币不能因强制药水/修理长期为负。

- 14–30级技能书有普通怪低概率和尸王较高概率双来源。
- 31–35级核心书主要由尸王殿、沃玛、祖玛、白野猪等竞争性来源产生。
- 连续七天全服无某核心技能书掉落时，只允许提高世界掉率，不允许后台直接赠送玩家。

### 6.1 装备层级

| 层级 | 等级范围 | 主要来源 | 作用 |

| T0 新手 | 1–7 | 出生、商店、低级怪 | 学会重量、耐久和出售 |
| T1 基础 | 8–14 | 商店、野外怪 | 建立职业倾向 |
| T2 洞穴 | 15–21 | 骷髅、僵尸、尸王 | 首次追求属性差异和技能书 |
| T3 职业 | 22–29 | 蛇谷、蜈蚣洞、商店补充 | 22级职业盔甲和职业武器 |
| T4 沃玛 | 30–35 | 沃玛、白野猪、尸王 | 形成可交易的中高端市场 |

### 6.2 稀缺性

- 商店只卖基础白装和消耗品，不卖沃玛、祖玛、赤月装备。
- 普通怪提供“能继续练级”的装备，Boss提供“改变身份”的装备。
- 极品属性允许存在，但必须有清晰上限和极低概率。
- 装备不绑定；死亡掉落风险、耐久和交易共同维持流通。
- 40级重装由专属Boss/地图产出，不做等级礼包。

## 7. 经济循环

### 7.1 金币来源

- 怪物金币掉落。
- 鸡鹿肉及低级材料出售。
- 商店回收普通装备。
- 采矿和矿石交易。
- 玩家之间的物品交易。

### 7.2 金币消耗

- 药水、随机卷、回城卷、毒药和护身符。
- 普通修理与特殊修理。
- 武器升级及失败损耗。
- 仓库扩展、行会创建和行会维护。
- 沙巴克报名、战争补给及传送服务。
- 摆摊/寄售手续费；不开放全服无摩擦拍卖。

### 7.3 经济健康目标

- 1–14级玩家完成一轮练级后应有正现金流。
- 15–29级药水与修理消耗占原始金币产出的 35%–55%。
- 30级后高效率地图消耗占产出的 50%–75%，利润更多来自物品而非裸金币。
- 普通玩家能够靠出售材料和中低级装备维持补给。
- 顶级玩家的裸金币时产不应超过同职业同等级中位数的3倍。
- 每周监控金币总量、人均金币、药水消耗、修理消耗、装备成交价和核心技能书成交价。

### 7.4 交易规则

- 面对面交易必须双重确认，修改报价后自动解除锁定。
- 地面掉落先给击杀者/队伍短暂保护，随后公开。
- 摆摊按地图区域开放；安全区内禁止遮挡NPC。
- 关闭当前全服拍卖入口，直到摆摊/寄售方案通过经济验收。

## 8. Boss循环

| Boss层级 | 代表目标 | 核心产出 | 社交规模 |
|---|---|---|---|
| 入门 | 尸王、骷髅精灵 | 技能书、基础极品 | 1–3人 |
| 中级 | 白野猪、沃玛教主 | 沃玛装备、高级书 | 3–8人 |
| 高级 | 祖玛教主、虹魔系 | 祖玛装备、稀有武器 | 8–20人 |
| 终局 | 赤月恶魔、双头金刚/血魔、牛魔王 | 赤月套、顶级武器、40级重装 | 行会级 |

Boss设计原则：

- 刷新时间有规律但带小范围随机偏移，避免脚本精确蹲点。
- 世界Boss不使用个人副本。
- 归属以有效贡献、队伍和最后阶段参与综合计算，避免单纯最后一刀。
- Boss死亡后产生全地图可感知信号，但不公开全部掉落。
- 首杀记录、最快击杀和行会归属进入赛季档案，不额外发数值装备。

## 9. PK、行会与沙巴克

### 9.1 PK

- 1–14级及新手地图启用新手保护。
- 15级后进入经典自由PK规则。
- 白名主动攻击获得灰/黄名状态，杀人累积PK值，红名死亡提高掉落风险。
- 安全区禁止攻击，守卫对红名和主动攻击者响应。
- PK不能成为无成本骚扰；红名洗点需要在线时间和世界活动，而非付费道具。

### 9.2 行会

- 创建行会需要沃玛号角和金币。
- 行会提供组织、聊天、成员关系和战争能力，不直接赠送大量属性。
- 行会仓库首期只存放可追踪物品，所有存取写审计日志。
- 行会的核心资源是玩家、Boss路线和战争补给，不是签到等级。

### 9.3 沙巴克

- 每周一次正式攻城，固定黄金时段。
- 报名、城门、皇宫占领、复活点和胜负结算必须服务器权威。
- 城主收益以荣誉、城市税收的一部分和功能便利为主，不发破坏平衡的独占神装。
- 沙巴克必须消耗药水、金币和装备耐久，成为经济主要回收器。

## 10. 新手体验与反流失

经典不等于不解释。前 30 分钟采用“轻引导、无强制任务链”：

1. 移动与攻击。
2. 割肉并卖给屠夫。
3. 买一瓶红药并使用。
4. 装备一件物品。
5. 学习7级技能的来源说明。
6. 指向比奇城和下一张地图，但不自动传送。

关键流失点与保护：

- **3级前没钱买药**：新手怪补足肉和低价杂物。
- **7级没有技能书**：基础书保底，但仍走掉落/交付仪式。
- **18级技能书断档**：尸王和矿区普通怪建立双供给。
- **22级装备断档**：职业盔甲有商店基础版，极品版靠掉落。
- **30级组不到人**：行会招募和区域组队频道开放，但不自动匹配传送。
- **40级目标消失**：Boss日历、行会战、重装和赤月路线在达到38级时显性预告。

## 11. 商业模式

推荐时长/月卡制：

- 月卡或游戏时间是唯一核心付费。
- 可售账号安全、角色改名等非数值服务，但首发可以全部关闭。
- 不售时装属性、仓库优势、随身商店、传送特权和自动补药。
- 任何新增收费项都必须通过“是否改变升级、产出、交易或战争优势”审查。

### 12.2 升级权威逻辑

怪物、任务、NPC和GM最终都调用同一个 `gain_experience` / `set_level` 服务：

```text
gain raw XP
→ apply allowed realm modifiers
→ add to current XP
→ while XP >= current level requirement
    subtract current requirement
    increment level
    load next requirement
    refresh base stats and equipment-derived stats
    restore HP/MP
    run level-up NPC/event hooks
→ emit GainExperience and LevelChanged
→ persist level, XP and max XP atomically
```

禁止各模块自行把经验截断在 `max_experience`。

### 12.3 内容编译校验

每次生成 `platinum_176_bundle` 时必须失败于以下情况：

- 白名单地图引用了不存在的地图或出口。
- 刷怪引用了未启用怪物。
- 怪物掉落引用了未启用物品。
- 三职业1–50关键技能没有合法来源。
- 关键装备没有怪物、Boss、商店或制作来源。
- 任何刺客、弓手、英雄或1.76后系统进入Bundle。
- Boss没有刷新、掉落或可达地图。

## 13. 验收体系

### 13.1 三条自动成长线

为战士、法师、道士各建立一条确定性加速验收线：

- 使用正式经验表，测试服通过全局倍率缩短墙钟时间。
- 不允许GM直接改等级跳过阶段。
- 每个等级段记录击杀数、死亡数、药水、修理、金币净变化、装备和技能。
- 必须实际经过地图入口、NPC、补给、掉落和学习技能。

检查点：7、14、21、29、35、40、45、50级。

### 13.2 关键通过条件

- 三职业均能从1级自然升到50级。
- 每个检查点的 `level/experience/max_experience` 保存、下线、重连一致。
- 所有必需技能均能由世界合法获得和学习。
- 不接受“GM发书”“GM发装备”作为通过证据。
- 任何阶段不存在持续负金币导致无法练级的经济死锁。
- 40级后至少存在三条同时可行的目标：升级、装备、行会/PvP。
- 两客户端共同打怪时，经验归属、掉落归属和拾取一致。
- Boss死亡、重生、掉落、归属、服务器重启均可恢复。
- 沙巴克完整跑通报名、攻城、占领、结算和奖励。

### 13.3 平衡观测指标

- 各等级段中位升级时长与P90。
- 每职业死亡率、药水消耗、金币净产出。
- 地图人口、怪物击杀率、Boss参与人数。
- 技能书首次掉落时间和市场价格。
- 装备层级分布、耐久消耗、死亡掉落。
- 7/14/21/29/35/40级留存。
- 行会加入率、组队时长、PK频率和沙巴克参与率。

## 14. 实施顺序

### P0：冻结版本边界

- 确认三职业、地图、怪物、技能、装备和系统白名单。
- 确认50级是验收边界而非硬上限。
- 确认时长/月卡、无数值商城。

### P1：修复成长内核

- 经验表、连续升级、属性刷新、满血满蓝、原子保存。
- 添加7/14/21/29/35/40/45/50级测试。
- GM和NPC改级改为复用统一等级服务。

### P2：交付1–21级

- 新手村、沃玛森林、半兽人洞、矿区。
- 肉、商店、药水、修理、低级装备和技能书。
- 三职业第一轮完整成长。

### P3：交付22–35级

- 毒蛇、蜈蚣、石墓。
- 职业盔甲、核心技能、尸王/白野猪/沃玛Boss。
- 交易、组队和金币平衡。

### P4：交付36–50级

- 祖玛、封魔、赤月、牛魔及40级重装。
- 祖玛/赤月装备市场和终局Boss。
- 三职业加速成长线跑通到50。

### P5：终局社会循环

- PK值、死亡掉落、行会、摆摊、Boss归属。
- 沙巴克全流程和经济消耗。
- 服务器重启、跨会话、多人一致性验收。

### P6：白金认证

- 关闭所有非1.76入口。
- 1倍经验真人试玩。
- 经济压力测试和至少一轮完整沙巴克。
- 发布可复现的1–50验收报告。

## 15. Definition of Done

只有同时满足以下条件，才能称为“白金1.76完整产品循环已交付”：

1. 三职业从1级自然成长到50级，不使用GM跳级。
2. 每个等级段都有合法地图、怪物、技能、装备和补给闭环。
3. 40级后Boss、装备、PK、行会和沙巴克能持续产生目标。
4. 世界经济在测试周期内没有金币死锁或恶性通胀。
5. 所有非1.76系统在白金Profile下不可见、不可调用、不可掉落。
6. 角色、装备、技能、任务、金币和地图状态可持久化并正确恢复。
7. 多人共享世界的战斗、掉落、交易和Boss归属一致。
8. 自动化验收、真人1倍速试玩和运营监控三类证据齐全。
