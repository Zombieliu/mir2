# Windows 新版启动器交付说明（2026-10-30）

用户选择：自动检查版本，只有点击「更新」才下载；已验证的本地版本可以直接开始游戏。

本轮发行源码以已交付的 unified updater `77a2007a449d1f437a8d411bfa41f105be992fcf` 为基线，整合新界面及可选更新。既有十语（含简体中文）、三个签名维护通道、版本单调序号、引擎来源绑定、恢复与首次启动健康检查保留。

## 玩家行为

- 首页本地验证通过后开放「开始游戏」，后台独立检查可选更新；HTTP 超时、失败或存在新版均不阻挡本地启动。
- 「查看更新」进入签名计划，展示版本和预计资料量；已有可验证安装时仍可选「先玩目前版本」。只有「更新」授权下载及激活。
- 下载显示实际新增字节、速度和当前下载估时；后续验证/安装不计入下载估时。首页与确认页不累加工作计时。
- 缺失或不可验证的安装不开放启动。更新失败、回退、签名及防回退约束沿用已有机制。
- 游戏仍使用既有登录与服务器兼容规则；本地可启动不等于在线玩法已经验收。

黑金武侠原画、文字、状态及按钮由原生 Win32/GDI 合成，支持 DPI 缩放、原生按钮、最小化和关闭。

## 安装与发行范围

游戏复用未改动的签名 Candidate `WN-CANDIDATE-20261029-unified-11`，原游戏来源 `1875c6c20e1285ffefc45ef6c21eab33e26fc536`。新安装器只更新外层安装版本及启动器包，不重新标记游戏来源。

完整安装器使用现有普通 AppID、目录记忆和十语选择；老玩家关闭游戏后覆盖原目录，新玩家正常安装。个人语言/显示偏好及服务器角色存档保留。独立 Validation 安装身份用于升级验证。

发行包以明确的现有 CMS 身份构建并独立校验；内部 CMS 与公开发行者 Authenticode 是不同门禁，不把内部签名称为公开发行者签名。最终安装文件、哈希、下载地址与本次安装/启动结果记录在外部交付证据中。
