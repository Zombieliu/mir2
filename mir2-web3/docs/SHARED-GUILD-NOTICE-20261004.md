现在普通已认证角色可按当前行会职位权限修改公告；事务提交成功后，同一行会跨 Zone
在线成员收到更新。权限、身份和行会修订号在耐久事务内重新核对，失败不会发送成功回包。

原版依据是 `PlayerObject.EditGuildNotice`、`GuildObject.NewNotice` 与
`GuildRankOptions.CanChangeNotice = 64`：最多 200 行，允许清空，使用 `update=-1`
终结写入。为现有原生客户端补发已提交的完整公告，不依赖客户端自动请求第 0 页。
多语言公告内容原样保留。此额外投影属于传输适配，不能称逐包完全一致。

四项普通包回归从 0 通过/4 失败变为 4 通过；邻接建会、邀请、跨 Zone、银行与 Buff
回归另有 4 项通过。覆盖未授权成员/非成员拒绝、200/201 行、清空、成员筛选、
已知保存失败与重试、正常退出/重登、独立 File 权威关闭后重开。
准备好的行会是机械前置，不代替 NPC 建会、原生鼠标或真人验收；本轮没有 PostgreSQL
重启验收，也没有发布新客户端或网关。职位管理、踢人、普通行会战和正常杀怪行会经验
继续列为待办，不因公告可用而将整个行会系统标为完成。
