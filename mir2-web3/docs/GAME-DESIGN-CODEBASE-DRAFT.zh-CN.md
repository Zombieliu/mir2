## 1. 产品总纲

### 1.1 一句话定义

【建议】一款以五职业成长、自由打宝、装备交易和行会争夺为核心的经典多人在线角色扮演游戏。玩家从个人冒险进入团队合作，达到100级后继续追求装备，并逐步参与庄园生产、行会建设和领地竞争。

### 1.2 目标玩家与体验

| 玩家倾向 | 希望获得的体验 | 本稿提供的主要目标 |
| --- | --- | --- |
| 单人冒险 | 有明确下一步，短时间上线也有收获 | 任务、职业技能、装备目标、补给与返程 |
| 打宝与交易 | 发现有价值的掉落，通过交换补足所需 | 怪物掉落、面对面交易、可验证的寄售流程 |
| 小队协作 | 职业配合能改变战斗结果 | 近战、远程、辅助、召唤的组合与共同挑战 |
| 行会组织 | 有长期共同目标与贡献用途 | 行会成长、公共仓库、沙巴克及后续建设 |
| 生产与经营 | 材料有人需要，投入能形成建设成果 | 原有采矿钓鱼；后续满级庄园与生产链 |

以上是目标用户假设，需通过试玩访问和行为记录验证。

### 1.3 产品承诺

【建议】每次上线能看到一个近期可完成目标；高价值装备有可解释的获取来源；交易、死亡和公共资产操作有清楚的结果反馈；团队玩法建立在真实共享世界和职业配合上。

【待定】单次游玩时长、每日投入预期、是否允许挂机、是否自动战斗、长期角色是否重置。代码中的追击或持续攻击不自动等于一套离线挂机产品规则。

## 2. 产品方向与当前代码基线

### 2.1 沿用的方向

依据[100级封顶与满级SLG成长规则](LEVEL100-SLG-PROGRESSION.zh-CN.md)：

1. 【方向】新角色从1级开始，职业范围为战士、法师、道士、刺客、弓箭手，兼顾男女角色。
2. 【方向】人物100级封顶，满级以后保留打宝、换装、交易、PK和行会目标。
3. 【方向】100级取得新增庄园、种植、自由建造、组合生产和行会领地的等级资格；仍需功能、来源、设施和权限满足条件。
4. 【方向】原有采矿、钓鱼、NPC合成、武器精炼、独立石材作坊、原版行会与沙巴克沿用各自规则，不统一推迟到100级。

## 3. 玩家体验与玩法循环

### 3.1 核心循环

【建议】准备补给 → 选择任务或打宝目标 → 前往地图 → 战斗与协作 → 取得经验、装备和材料 → 拾取整理 → 学技能、换装或交易 → 挑战下一目标。

满级后增加：取得材料 → 加工或生产 → 个人设施与行会仓储 → 建设、补给与运输 → 共同战斗或领地目标 → 形成新的材料需求。

### 3.2 不同时间尺度的目标

| 尺度 | 玩家行动 | 体验检查 |
| --- | --- | --- |
| 一次交战 | 接敌、攻击或施法、走位、用药、拾取 | 操作有响应，命中、伤害、受击和死亡可辨认 |
| 一段短流程 | 完成任务、补一次药、学习技能、打到一件可用装备 | 能解释自己获得了什么，下一步做什么 |
| 一次上线 | 完成自主目标，与朋友共同挑战或提供物资 | 收益与投入可理解，失败后有恢复路径 |
| 一周或更长 | 追求稀有掉落、参与行会活动、准备共同挑战 | 目标有进展，组织内不同贡献都有用途 |
| 满级之后 | 继续装备成长，选择生产建设与领地活动 | 战斗、交易、生产形成持续需求 |

【待定】日常、周常是否强制，重复任务上限和奖励。现有奖励配置必须逐项核算，不能直接叠加成新的首发经济。

## 4. 世界、叙事与内容舞台

【代码】现有内容以比奇、盟重、洞穴、矿区、沃玛及其他经典地图和怪物资源为基础。地图通过内容配置筛选，进入与通行还受服务端规则影响。

【建议】叙事主线采用“村庄异常 → 城镇求援 → 洞穴与矿区调查 → 地下势力威胁 → 行会共同守护与争夺资源”的结构，把任务、怪物和后续行会建设串起来。

| 内容层 | 主要用途 | 制作要求 |
| --- | --- | --- |
| 村庄与城镇 | 教学、补给、交易、社交与安全返程 | 服务NPC、道路和功能入口清楚 |
| 普通野外 | 熟悉职业操作、材料与基础装备获取 | 怪物密度、返程和药耗适合目标阶段 |
| 洞穴与矿区 | 更强敌人、职业练习、采矿与装备目标 | 入口可达，关键目标可找到，有撤退选择 |
| 高阶挑战地图 | 小队打宝、Boss与稀有物品 | 机制、奖励归属、刷新和失败成本明确 |
| 行会与战争区域 | 公共活动与长期组织目标 | 时间、参与资格、胜负、战后处理可解释 |
| 新增庄园与建设区 | 满级生产与经营 | 真实地块、设施、材料和权限逐项接通 |

【待定】正式世界观、主线人物、阵营名称、故事章节与结局；每个区域对应的等级段、地图清单和Boss列表。源地图数量不直接决定首发地图数量。

## 6. 登录、角色与新手旅程

### 6.1 进入游戏

【代码】玩家流程为登录 → 选角或建角 → 进入世界。Web有账号密码、Passkey和Sui钱包身份入口；钱包不是唯一入口。角色创建UI有五职业、男女选择及最多4个角色的限制，服务端还执行内容配置与身份校验。

【建议】选角页显示职业定位、角色等级和继续目标；首次进入世界首先交付移动、战斗和奖励反馈。

【待定】正式登录方式组合、角色命名、删角等待与恢复规则、多端登录规则。不得把QA账号、调试发物品或坐标传送作为玩家旅程步骤。

### 6.2 新手版本选择

【代码】当前有原有任务及显式选择的 `newcomer-v1`、`newcomer-v2`。未设置 `MIR2_QUEST_CADENCE` 时不自动启用V1或V2；试玩环境示例显式选择V2。

【建议】产品新手路线采用V2作为初稿基线。V2目前针对战法道，需补齐刺客与弓箭手的等价教学和奖励，才能覆盖五职业方向。

### 6.3 V2路线与设计时长

V2的22个主线、4个一次性成长领取节点有配置及服务端事件路径；下列时长来自[新手V2设计](NEWCOMER-1-30-V2-DESIGN.md)，属于设计预算，未在本轮进行真人计时验证。

| 章 | 等级目标 | 主线数 | 核心预算 | 玩家学会什么 |
| --- | --- | ---: | ---: | --- |
| 初次出战 | 1→8 | 4 | 8分钟 | 领补给、装备武器、识别目标、首个职业技能 |
| 独立出行 | 8→16 | 4 | 12分钟 | 到比奇、购买补给、职业练习与15级奖励 |
| 洞穴救援 | 16→20 | 4 | 15分钟 | 进入D001、应对洞穴敌人、运用职业技能 |
| 矿口防线 | 20→25 | 4 | 15分钟 | 进入D401、使用穿刺、法术或毒术等战术 |
| 沃玛侦察 | 25→27 | 3 | 18分钟 | 远征准备、新技能、识别撤退路线 |
| 完成远征 | 27→30 | 3 | 22分钟 | 在D022综合战斗、返程交付、选择后续目标 |
| 学习与恢复余量 | 全程 | — | 30分钟 | 找路、补给、死亡恢复与正常操作学习 |

目标总时长120分钟；首次战斗不晚于入场3分钟、首个职业技能不晚于10分钟，均属于待验证目标。

### 6.4 任务与奖励规则

- 【代码】成长领取节点为15、20、25、30级，并有对应主线前置；通过普通接取与完成流程结算。
- 【代码】职业练习核验真实行为，例如技能学习、法术伤害、治疗或装备事件；具体节点要求不同。
- 【代码】V1已有奖励或进行中进度会限制V2启用，需要独立的旧角色兼容方案。
- 【代码】前端操作教程主要按出站动作和窗口事件推进；正式任务以服务端进度为准。两者分别验收。
- 【建议】毕业时展示装备、技能、挑战三个下一目标，并提供正常获取与地图路线提示。

【待定】是否保留两小时目标、两新增职业如何教学、旧角色如何转换版本、30级后的第一条明确目标。

## 7. 等级、属性与装备成长

| 满级后 | 装备与组织、生产目标并行 | 稀有掉落、设施与公共物资需求、共同活动 |

### 7.2 当前数值基线

【代码】默认经典配置的怪物经验倍率为1–21级2倍、22–35级3倍、36–50级4倍；金币、掉落倍率为1。倍率范围外经验倍率回退为1。经验达到门槛可连续升级，升级重新计算属性并回满HP/MP。

【方向】100级封顶应统一覆盖击杀、任务及其他人物经验入口；达到100级后不升101级，人物经验不自动换成金币或永久战斗属性。现有500项经验表与50级验收配置须保留其原始含义。

【待定】31–100逐级经验表、各阶段典型战斗与升级耗时、药钱和修理负担、超100级旧角色处理。上述内容不能只靠提高倍率完成设计。

### 7.3 装备价值与追求

【代码】装备具有职业、等级及其他穿戴条件，实例还可能带附加属性、耐久、强化、绑定、租借、封印或镶嵌等状态；具体能力受内容配置与入口限制。

【建议】装备追求按“基础换装 → 合适属性与极品 → 职业关键装备 → 稀有与团队目标”组织。稀有度颜色、套装与保底机制需要单独冻结，不直接把旧方案中的颜色分层当作当前代码事实。

每件进入本服成长线的装备需有：职业与槽位、等级/属性条件、基础及附加属性、耐久与重量、获取地图和怪物、掉率或兑换成本、交易/绑定、修理和退出用途。

【方向】71–100需要本服专用装备与属性编排。已有资源盘点只提供候选来源，不能直接把源模板等级改高就宣称完成成长曲线。

## 8. 怪物、Boss、地图与交通

### 8.1 战斗内容规格

【代码】默认配置包含普通怪物与Boss白名单；Boss标记有Ghoul、WhiteBoar、EvilCentipede、WoomaTaurus、ZumaTaurus、EvilBigApe、RedMoonEvil。标记数量不等于完整可挑战、可掉落并已平衡的Boss数量。

【建议】普通怪物教学逐步引入近战追击、远程攻击、群体威胁、状态效果和召唤；Boss强调可辨认的危险、职业配合和奖励目标。

### 8.2 普通交通规则

【代码】地图连接点要在服务端确认角色到达对应格后发起切图；回城复活等走各自规则。当前Web世界地图未接任意目的地传送回调。

【建议】地图界面提供当前位置、出口、任务方向和服务点；传送服务有明确NPC、道具、资格与费用。

【待定】首发地图清单、各区域建议等级、交通收费、安全区边界、是否提供收费导引。建议等级与硬性入场等级分开记录。

## 9. PvP、死亡与风险分层

### 9.1 六种攻击模式

【代码】当前UI显示和平、组队、行会、敌对行会、善恶、全体。服务端判定如下：

| 模式 | 玩家攻击范围 |
| --- | --- |
| 和平 | 不攻击玩家 |
| 组队 | 排除队友 |
| 行会 | 排除同公会成员 |
| 敌对行会 | 仅允许敌对行会目标 |
| 善恶 | 要求目标PK值至少100 |
| 全体 | 可攻击其他玩家，仍受安全区和存活等限制 |

【代码】攻击者或目标处于安全区时禁止PvP。安全区不能简单理解为绝对免死区，已有持续毒、流血等伤害路径需分别判断。

### 9.2 死亡与物损

【代码】共享Zone已接入的战斗、持续及环境伤害导致死亡时，网关调用物损结算并将新掉落注册回共享地面世界；同一条命避免重复结算。物损函数的基线是：

| 当前PK值 | 物损选择规则 |
| --- | --- |
| 小于100 | 以确定性抽样按1/8比例触发选取1件 |
| 100–299 | 选取1件 |
| 至少300 | 选取2件，优先装备 |

候选来自符合规则的携带物品与装备；`Don'tDrop`等保护标记会影响结果，特殊销毁标记可能导致销毁，因此不能承诺每次都有相同数量的可拾取掉落。死亡扣经验与其他特殊死亡路径本轮未完整核对。

【代码】死亡角色有回城复活入口，恢复满HP/MP并回绑定点；最终损失提示与恢复体验仍需客户端验证。

【待定】新手阶段保护、红名获得与消除节奏、抢怪与恶意阻路处理、死亡前后提示、特殊地图风险。调整规则时同时核算装备流失、玩家挫败与交易需求。

## 11. 经济、交易与商业化

### 11.1 经济循环

【建议】以金币、装备和材料构成普通经济。资源通过战斗、任务及已开放生活玩法进入玩家手中，通过药品、修理、服务、合成及后续建设形成消耗。

玩家间买卖主要转移既有资产；手续费才构成对应金币消耗。核算时分别记录系统新增、系统回收和玩家间流转。

【代码】普通面对面交易和金币寄售使用Gold；内部还有其他货币/点券状态与商城路径。城市币、平台点券与链上资产不能自动当作同一货币。

### 11.2 面对面交易

【代码】网关有双人共享交易协调：要求同图、彼此正面相邻、双方存活、对方允许交易且未处于冲突状态；物品受禁止交易、绑定、租借等限制。金币与物品进入托管，按双方确认执行共享结算或回滚。

【建议】窗口始终显示双方物品、数量、金币和确认状态；内容改变时清楚显示需重新确认的状态。正常玩家完成一次真实双账号交换作为交付条件。

### 11.3 寄售市场

【代码】现有包处理为固定价寄售，列表每页10条；要求售价大于0，上架物品进入托管；购买检查金币、空间，不能买自己的商品。卖家领取成交款扣除 `ceil(成交价/20)`，约5%佣金。

【待验证】本轮未证实当前全服市场的共享注册及跨玩家成交持久同步；默认经典配置还禁用 `auction.` 内部动作前缀。内部处理与UI存在不足以说明全服市场已开放。

【待定】是否首发寄售、上架期限与数量、手续费收取时机、成交款领取方式、是否需要真正竞价拍卖。

### 11.4 付费设计

【建议】先验证普通游戏循环。付费候选可以是外观、月卡、内容通行证及适度便利；商品不得绕过本稿尚未定义的成长与装备规则。

【代码】商城目录与相关处理存在；默认经典配置禁用 `gameShop.`、`shop.buyCredit` 等内部动作。商品代码与Gold/Credit状态不代表正式支付、充值、退款及完整履约已经接通。

【待定】付费方式、价格、权益、战力边界、货币兑换、支付渠道和售后。旧商业稿中的收入占比、营收示例与节点奖励比例保留为假设，不作为本稿运营承诺。

## 12. 组队、行会与沙巴克

### 12.1 组队与协作

【代码】有邀请、成员状态、退出及任务分享相关处理；共享Zone有组队经验分配路径，存活的归属玩家及同组玩家参与分配，余数给归属者，普通掉落不会给每个成员复制一份。

【待验证】完整跨会话邀请资格、队伍上限、成员离线与换图、任务共享条件。现有经验分配路径不能自行加写为“仅附近队友获得经验”；最终范围规则需明确。

【建议】小队奖励说明经验、普通物品、任务物品和召唤击杀分别如何归属，让玩家能预期共同战斗结果。

### 12.2 行会

【代码】共享行会创建最低22级，消耗100万金币和1个沃玛号角；行会名称长度配置为3–20个UTF-16单位。已有等级经验、成员上限、Buff和公共仓储相关规则。

【代码】共享行会与角色资产联合提交；金币提取与物品存取受会长或职级权限约束。原版行会领地另有NPC租赁、续租、回城及传送等处理。

【待统一】共享行会数据中的战争费用为30000，本地Stage5相关常量仍有3000；本稿不选择其中之一作为最终宣战价格。

【建议】行会组织目标包括共同打宝、补给、公共资产管理和周期活动。新增建设权限与贡献记录需在具体系统中另行定义。

### 12.3 沙巴克与领地战争

【代码】可找到城门、守卫、维修、税率、归属和通行资格等处理；本轮未完整核验“报名 → 定时开战 → 多人攻防 → 胜负 → 税收”的共享闭环。

【建议】沙巴克作为原有行会竞争目标；普通成员依原规则参与，不新增100级门槛。新增庄园与生产可以在验收后提供常规补给，不自动改变原城堡胜负判定。

【待定】活动时段、参与资格、胜负条件、人数与承载目标、奖励、归属期限、战后保护及异常结束处理。原版行会领地与新增自由建造领地分别验收。

## 13. 生活玩法、制作与宠物

### 13.1 普通采矿和钓鱼

【代码】采矿需要可采矿武器，对矿点执行普通挥击，包含矿脉耗尽、恢复、出矿、矿镐损耗与纯度。内置矿点石量上限配置为80，恢复间隔配置为5分钟；空矿点在后续挥击时检查恢复时间并随机回补。命中率配置为25%，命中后再以10%进入出矿判定，实际产出仍受矿表、模板和接收空间等条件影响。

【代码】钓鱼有鱼竿、附件、鱼饵、抛竿/收竿判定、耐久与掉落，还可能产生怪物事件；有效水域、地图格数据和来源需按实际地图验证。

【建议】生活玩法提供补给材料、交易品和可选择的节奏变化。原版采矿与钓鱼不统一设为100级开放。

### 13.2 原有合成与独立石材作坊

【代码】普通配方制作检查材料、金币、工具耐久与接收空间，按配方概率出货；失败也可能消耗投入。默认内容是否开放对应配方与入口需逐项确认。

【代码】独立作坊有“矿石 → 封存原石 → 鉴定/切割 → 材料”的流程；封存时结果已固定，切割不重抽，保留原物品身份。三档鉴定费为100/250/500金币，切割费为1500/2500/3500金币。

该分支默认关闭，需显式启用、可写持久来源与批准NPC；它不等于大SLG总目录已开启。

【待定】作坊是否进入首发、原石来源、结果概率、展示方式、材料用途和整体收益。未知结果与费用须在玩家投入前说明。

### 13.3 智能宠物与战斗召唤物

【代码】智能宠物有拥有、召唤/收回、命名、模式、拾取过滤与维护等路径；拥有上限为10只，同类不重复。普通可获取来源和各类型效果仍需结合内容配置核验。

道士等职业的战斗召唤物按技能与战斗规则处理，和拾取型智能宠物分开说明。

【待定】首发宠物类型、获取途径、拾取规则、维护成本和是否收费。已有英雄、师徒等辅助系统入口，也须在首发清单中逐项决定范围。

## 14. 100级后的新增SLG

本节为【方向＋建议】，以[庄园与领地设计](SLG-PRODUCTION-TERRITORY-DESIGN.zh-CN.md)、[制作设计](SLG-CRAFTING-DESIGN.zh-CN.md)及[生产目录](SLG-PRODUCTION-CATALOG.v0.2.json)为展开依据。总目录当前关闭，个人生产持久适配代码也没有自动形成普通玩家入口。

### 14.1 第一阶段：个人庄园

- 100级获得等级资格，满足开关、来源、设施和权限后从正常NPC领取地块。
- 沿用草案测试起点：24×24格可建区，初始4块农田，后续最多8块。
- 谷物30分钟、药草60分钟成熟，每次基础收获2；成熟不腐烂，离线继续生长。
- 背包不足则保留成熟作物；播种与收获以服务端成功结果为准。
- 仓库和加工台先提供少量、用途明确的功能。

以上尺寸、数量与时间都是待试玩的设计参数。NPC坐标、种子、地块与物品模板须落到正常获取和交互流程。

### 14.2 第二阶段：生产与行会公共设施

【建议】普通采矿、种植及已开放采集来源，经加工进入建材和常规补给，再进入个人使用或行会公共仓库。

示例生产链：木材 → 木板；矿物与木炭 → 连接件；木板、连接件、绳索 → 建筑部件；药草、谷物 → 常规补给包。

每条链同时具备真实来源、配方、金币/工期、设施、领取、绑定、交易与消耗用途。尚无正常来源的材料及其下游成品继续关闭。

### 14.3 第三阶段：战争供给与多领地竞争

【建议】先以角色正常携带物资支持共同战斗，再定义据点、资源线、占领与外交。国家、阵营、离线行军和国战结算另立系统规则。

【方向】达到100级不要求先凑齐毕业装备；原有打宝、PK和沙巴克继续。新增生产初期不批量制造毕业装备或永久战斗属性。

【待定】公共地块数量、建设权限、产能和战争消耗、领地归属期限、战败损失、退出行会与公共资产处理。

## 16. 运营、链上能力与版本边界

【建议】首期运营围绕普通玩家旅程、经济和行会协作形成活动。社区节点的运营奖励与游戏内行会战利品分别设计。

【代码】有Sui身份及独立链上矿场桥接代码，可信Relayer确认可触发矿物、金币及矿脉状态更新，并有事件去重；本轮未核验合约部署、真实签名、链确认到资产交付的完整流程。

【待定】链上矿场是否进入首发、与普通采矿的关系、失败交付与满包恢复、资产规则；不得由登录入口或桥接代码推断已具备完整链上经济。

【待定】赛季长度、是否重置、跨服、社区节点准入与奖励、活动排期、维护补偿和客服工具。旧商业草案中的并发、付费和收入数字作为待验证假设。

## 18. 玩法验证与后续修订

### 18.1 首轮要回答的问题

| 1–100是否连续可玩 | 每段地图、敌人、奖励、成本及装备提升，封顶边界 | 100级方向待落实 |

| 经济是否有正常循环 | 金币新增/回收、药钱修理、装备材料产消、成交行为 | 待形成同版本样本 |

### 18.2 具体完成条件示例

一个“学习并使用首技能”的完成条件可以写为：普通新角色按本职业取得合法技能书，在满足等级后学习成功；技能页与快捷栏显示正确；用技能完成对应有效行为，服务端任务进度更新；保存重登后技能与奖励状态仍一致。材料、等级或空间不足时显示原因，重复操作不重复授奖。

一个“庄园收获”的完成条件可以写为：100级合格角色在已开放地块使用正常来源种子，成功播种才扣种子；成熟时间由服务端决定；离线重登继续；收获只交付一次；满包时作物保留，腾出空间后可领取；公共观察者看到同一结果。

体验结论同时记录玩家观察与问题原因，不把“按钮发过一次请求”“源码存在”或“旧版本测试通过”直接当作当前版本可玩结论。
