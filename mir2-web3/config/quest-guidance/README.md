# 前40级新手引导配置

`newcomer-v1.json` 是可选的客户端展示配置。适用当前 Crystal quest DB 117、
`platinum_176` v25 的战士、法师、道士前40级内容。三职业各138项，共144个不同ID。
其中前15级仍为每职业42项；16–25新增62项；26–40新增34项，不代表必须全部完成才能升级。
这是优化版引导，不是原版1:1布局验收证据。

## 游戏中的变化

- 推荐：出生村、职业导师、森林与蛇谷成长链、老人后续；前置任务完整保留。
- 支线：运送戒指/配方/物资等跑腿和额外收集，减少与成长链争夺注意力。
- 挑战：骷髅与古代半兽人洞穴任务，提示准备补给，不以接取等级承诺难度。
- 低优先级：q154空目标零奖励的皇帝跨图任务，保留入口但不优先引导。
- 16–25级推荐茶水、Shok、医药与车队链；Wooma、亡魂和洞穴任务归挑战，保留完整前置。
- 25级古书支线按110→111→108→109排序，不按任务编号误排。
- 26–40级新增任务按真实前置拓扑排序；Holy Sword、Prajna、亡魂和废墟链保留完整，不把后续任务提前展示。
- 26–40级推荐成长路线补充 `117→118→119` 矿洞补给链、`125→126→127→128` 村长历史链和独立运输 `134`；高难战斗与特殊事件链仍为可选挑战。
- 详情加入就近兼做、交付材料保留、Quest Diary操作和职业技能提示。
- 新手模式不显示数量为0的固定物品奖励；需要选择的奖励保留入口和原始编号，避免无法交任务。

列表只整理服务器提供的任务；任务等级、职业限制、前置、完成状态、奖励数值、
追踪选择、学习技能条件及自动寻路规则均由现有流程决定。不会自动接受任务。
学到技能的提示不代表客户端已替玩家学习或验证成功。

## Windows 启用

配置编译在新客户端内，现有旧安装包不会自动获得这些改动。
在启动新构建的客户端前设置：

```powershell
$env:MIR2_QUEST_GUIDANCE = 'newcomer-v1'
# 然后使用原来的客户端启动命令；资产、Gateway和登录配置沿用原设置。
```

不设置变量，或设为 `crystal`，使用原版展示。切换后需重新启动客户端；
配置在启动时读取一次，不增加每帧文件读取。

服务器使用 `MIR2_QUEST_CADENCE=newcomer-v1` 时，新手日记保留服务器明确的
Daily、Weekly、Repeatable分组，不用静态支线分类覆盖它们。客户端单独开启
引导不会把普通任务改成周常；周期与领奖由服务器决定。

## 验证与维护

在项目根运行：

```powershell
node --test apps/web/scripts/quest-agent/test-newcomer-guidance.mjs
$env:MIR2_QUEST_AGENT_MAX_LEVEL = '40'
$env:MIR2_QUEST_AGENT_GUIDANCE = 'newcomer-v1'
node apps/web/scripts/quest-agent/generate-route-manifest.mjs
```

生成的 `*-1-40-newcomer-v1.json` 使用独立文件名，保留原路线数据并增加guidance字段。
仍支持输出15级子集。测试使用当前任务源核对144项覆盖、职业分支和前置顺序，防止内容更新后引导漂移。
原版任务数值和内容文件不在此配置中重写。

## 下一轮实测后才能调整的内容

三职业分别记录每阶段实际等级/经验、耗时、药水消耗、死亡次数、跨图次数、
背包阻塞和可用技能。依据这些结果再调经验、收集数量或奖励装备。
当前没有新增强制施法教学任务，也没有宣称42项足以无刷怪升到15级，或138项足以无刷怪升到40级。
新版Windows列表/详情截图和连续游玩验收仍需完成。
