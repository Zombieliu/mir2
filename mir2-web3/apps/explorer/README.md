# NUMERON Atlas prototype

Standalone Next.js prototype for the public-facing **Legend of Rebirth / 传奇重生** world explorer.

The current data is intentionally static and exists to validate information architecture, visual direction, search interaction, public-data boundaries, and responsive layout before connecting real game APIs.

```bash
npm install
npm run dev
```

The local prototype runs at `http://localhost:3090/zh-CN`.
