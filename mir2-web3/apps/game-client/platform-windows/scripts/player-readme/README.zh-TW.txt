Numeron - Legend of Rebirth — 邀請試玩

適用於 Windows 10/11 x64。安裝程式會使用目前 Windows 使用者的本機程式資料夾，並可建立桌面捷徑。若缺少 Microsoft Visual C++ x64 執行階段，Windows 會為該微軟元件要求系統管理員權限。如要求重新啟動，請先重新啟動 Windows 再開啟遊戲。

可選 English、繁體中文、Português (Brasil)、Русский、हिन्दी、Bahasa Indonesia、Tiếng Việt、ไทย 或 العربية。首次安裝會以安裝語言設定遊戲；既有的遊戲語言偏好優先保留。可在登入畫面或遊戲內選項更改語言。偏好按 Windows 使用者儲存在遊戲資料夾外。玩家姓名、帳號輸入與玩家聊天保持原文。

啟動 Numeron - Legend of Rebirth。每位玩家請自行註冊不同帳號。帳號須為 3–15 個英文字母或數字；密碼須為 10–15 個英文字母或數字，不得與帳號相同，也不得使用常見弱密碼。請勿多人同時共用帳號。

按 Q 開啟任務，使用地圖及任務引導按鈕尋路。關閉遊戲前請正常退出角色，以保存進度。進度由伺服器儲存，重新安裝客戶端不會重設進度。

本版支援九種介面語言，內建所需字型，包含阿拉伯文連寫、天城文及泰文。保留法師預覽特效、連續預覽動畫、安靜啟動及固定像素視窗尺寸修正。

若 Windows 阻止啟動（包括錯誤 4551），請保持應用程式保護啟用。向開發者提供錯誤碼與安裝記錄，或請組織管理員檢查原則，並索取受信任簽章版本。套件內部完整性簽章不等於 Windows 發行者簽章。若安全的使用者目錄可寫入，安裝程式會將啟動失敗記錄於 LocalAppData/mir2-web3/installer-last-launch.txt。啟動失敗不代表安裝失敗。

這是邀請測試版。戰士 0–30 級已試玩驗收，法師與道士仍待全程人工驗收。同時登入上限依伺服器目前設定，不代表已證明 50 或 100 人穩定容量。部分專有名稱及伺服器提供的文字可能保留原語言。

可從 Windows 設定的應用程式清單，或安裝的解除安裝捷徑移除客戶端。語言偏好會保留，伺服器帳號與角色不會刪除。本說明優先於為溯源保留的舊封存說明。
