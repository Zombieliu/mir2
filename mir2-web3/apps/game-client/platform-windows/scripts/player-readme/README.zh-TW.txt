Numeron - Legend of Rebirth — 邀請測試版

適用 Windows 10／11 x64。安裝程式會安裝至目前 Windows 使用者的本機程式目錄，並可建立桌面捷徑。若缺少 Microsoft Visual C++ x64 執行階段，Windows 會要求允許安裝該微軟元件的系統管理員權限；若要求重新啟動，請先重新啟動再開啟遊戲。

安裝時可選 English、繁體中文或 Português (Brasil)。首次安裝會以此設定遊戲語言；已有的遊戲語言偏好優先保留。之後可在登入畫面或遊戲內選項切換。語言偏好按 Windows 使用者儲存在遊戲目錄之外。帳號、玩家名稱和聊天內容保持輸入原文。

從 Numeron - Legend of Rebirth 捷徑啟動。每位玩家請建立各自的帳號。帳號需為 3–15 位英文字母或數字；註冊密碼需為 10–15 位英文字母或數字，不可與帳號相同，也不可使用常見弱密碼。請勿以同一帳號同時登入。

本次更新包含原生三語介面與語言偏好保存、內附繁體中文字型、法師預覽的加色混合修正、輸入名稱時保持動畫連續、Windows 啟動不彈出主控台且錯誤對話框使用所選語言，以及高 DPI 顯示器固定像素視窗尺寸修正。

這是邀請試玩版本，並非容量驗收或正式公開發行。戰士 0–30 級流程已實際試玩；法師與道士仍待全程玩家驗收。部分原始專有名稱及伺服器傳入文字可能保留原語言。套件內部完整性簽章不等同公開 Windows 程式碼簽章。

可從 Windows「設定 > 應用程式」或已安裝的解除安裝捷徑移除遊戲。每位使用者的語言偏好會保留。解除安裝客戶端不會刪除伺服器帳號或角色。
