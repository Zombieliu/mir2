Numeron - Legend of Rebirth — 邀请试玩

适用于 Windows 10/11 x64。安装程序使用当前 Windows 用户的本地程序文件夹，并可创建桌面快捷方式。如果缺少 Microsoft Visual C++ x64 运行库，Windows 会为该微软组件请求管理员权限。如要求重启，请先重启 Windows 再启动游戏。

安装时可选择 English、简体中文、繁體中文、Português (Brasil)、Русский、हिन्दी、Bahasa Indonesia、Tiếng Việt、ไทย 或 العربية。首次安装会用安装语言设置游戏；已有的游戏语言偏好优先保留。可在登录画面或游戏内选项更改语言。偏好按 Windows 用户保存在游戏文件夹之外。玩家姓名、账号输入和玩家聊天保持原文。

启动 Numeron - Legend of Rebirth。每位玩家请自行注册不同账号。账号须为 3–15 个英文字母或数字；密码须为 10–15 个英文字母或数字，不得与账号相同，也不得使用常见弱密码。请勿多人同时共用账号。

按 Q 打开任务，使用地图和任务引导按钮寻路。关闭游戏前请正常退出角色以保存进度。进度由服务器保存，重新安装客户端不会重置进度。

本版支持十种界面语言，内置所需字体，包括完整简体中文、阿拉伯文连写、天城文和泰文。保留法师预览特效、连续预览动画、安静启动和固定像素窗口尺寸修正。

若 Windows 阻止启动（包括错误 4551），请保持应用保护开启。向开发者提供错误代码和安装日志，或请组织管理员检查策略，并索取受信任签名版本。安装包的内部完整性签名不等于 Windows 发布者签名。如果安全的用户目录可写，安装程序会将启动失败记录到 LocalAppData/mir2-web3/installer-last-launch.txt。启动失败不代表安装失败。

这是邀请测试版。战士 0–30 级已试玩验收，法师和道士仍待完整人工验收。同时登录上限依服务器当前配置，不代表已证明 50 或 100 人稳定容量。部分专有名称和服务器提供的文字可能保留原语言。

可从 Windows 设置的应用列表，或已安装的卸载快捷方式移除客户端。语言偏好会保留，服务器账号和角色不会删除。本说明优先于为溯源保留的旧归档说明。

自动更新
首次安装 r8 后，请使用桌面快捷方式启动。启动器会检查签名更新清单，只下载发生变化的文件。更新前请保存进度并关闭游戏。替换失败或中断时会在启动前恢复旧文件；新版首次启动失败也会回退。已完成的下载会重用，未完成的文件会重试。语言偏好和服务器角色进度会保留。更新服务暂时无法连接时，仍可启动已验证的安装版本。

显示大小
在登录画面左下角点击“窗口分辨率”，可使用“自动（推荐）”或选择支持的 4:3 窗口大小。场景、文字、按钮和鼠标点击区域会一起缩放；超出屏幕可用范围的选项不可选。选择会保存到下次启动，更新时也会保留。这些选项适用于窗口模式；全屏模式会保持原画面比例。
