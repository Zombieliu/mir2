Numeron - Legend of Rebirth — การทดลองเล่นแบบเชิญ

ติดตั้งบน Windows 10/11 x64 ตัวติดตั้งใช้โฟลเดอร์โปรแกรมภายในของผู้ใช้ Windows และสามารถสร้างทางลัดบนเดสก์ท็อปได้ หากไม่มีรันไทม์ Microsoft Visual C++ x64 ระบบจะขอสิทธิ์ผู้ดูแลระบบสำหรับส่วนประกอบของ Microsoft นี้ หากได้รับแจ้งให้เริ่ม Windows ใหม่ ให้ดำเนินการก่อนเปิดเกม

เลือก English, 繁體中文, Português (Brasil), Русский, हिन्दी, Bahasa Indonesia, Tiếng Việt, ไทย หรือ العربية เมื่อติดตั้งครั้งแรก ภาษานี้จะเป็นค่าเริ่มต้นของเกม หากเคยบันทึกภาษาไว้แล้วจะใช้ค่าเดิมก่อน คุณเปลี่ยนภาษาได้ที่หน้าลงชื่อเข้าใช้หรือในตัวเลือกของเกม ค่าภาษาบันทึกแยกตามผู้ใช้ Windows นอกโฟลเดอร์เกม ชื่อผู้เล่น ข้อมูลบัญชีที่กรอก และข้อความสนทนาของผู้เล่นจะคงเดิม

เริ่ม Numeron - Legend of Rebirth ผู้เล่นแต่ละคนควรสร้างบัญชีของตนเอง รหัสบัญชีต้องมีตัวอักษรละตินหรือตัวเลข 3–15 ตัว รหัสผ่านตอนสมัครต้องมีตัวอักษรละตินหรือตัวเลข 10–15 ตัว ต้องต่างจากรหัสบัญชีและไม่ใช่รหัสผ่านที่เดาง่ายทั่วไป อย่าใช้บัญชีเดียวเล่นพร้อมกันหลายคน

กด Q เพื่อเปิดภารกิจ ใช้แผนที่และปุ่มแนะนำภารกิจเพื่อค้นหาเส้นทาง ออกจากตัวละครตามปกติก่อนปิดเกมเพื่อบันทึกความคืบหน้า ความคืบหน้าเก็บอยู่ที่เซิร์ฟเวอร์ การติดตั้งไคลเอนต์ใหม่จะไม่รีเซ็ตความคืบหน้า

รุ่นนี้รองรับภาษาหน้าจอเก้าภาษาและมีแบบอักษรสำหรับอักษรที่รองรับ รวมถึงการเชื่อมอักษรอาหรับ อักษรเทวนาครี และภาษาไทย ยังคงการแก้ไขเอฟเฟกต์ตัวอย่างจอมเวท แอนิเมชันต่อเนื่อง การเริ่มเกมโดยไม่มีหน้าต่างคอนโซล และขนาดหน้าต่างแบบพิกเซลคงที่

หาก Windows ปิดกั้นการเริ่มเกม รวมถึงข้อผิดพลาด 4551 โปรดเปิดระบบป้องกันแอปไว้ ส่งรหัสข้อผิดพลาดและบันทึกการติดตั้งให้ผู้พัฒนา หรือให้ผู้ดูแลระบบขององค์กรตรวจสอบนโยบาย ขอรุ่นที่มีลายเซ็นเชื่อถือได้ ลายเซ็นตรวจสอบความถูกต้องภายในแพ็กเกจไม่ใช่ลายเซ็นผู้เผยแพร่ของ Windows หากตำแหน่งผู้ใช้ที่ปลอดภัยเขียนได้ ข้อผิดพลาดจะบันทึกที่ LocalAppData/mir2-web3/installer-last-launch.txt การเริ่มเกมไม่สำเร็จไม่ได้หมายความว่าติดตั้งไม่สำเร็จ

นี่คือรุ่นทดลองแบบเชิญ เส้นทางนักรบระดับ 0–30 ได้ผ่านการทดลองโดยผู้เล่นแล้ว ส่วนจอมเวทและนักพรตยังต้องตรวจรับตลอดเส้นทาง จำนวนผู้เข้าเล่นสูงสุดขึ้นอยู่กับการตั้งค่าเซิร์ฟเวอร์ปัจจุบัน ไม่ได้ยืนยันว่ารองรับผู้เล่น 50 หรือ 100 คนได้อย่างเสถียร ชื่อเฉพาะและข้อความบางส่วนจากเซิร์ฟเวอร์อาจคงภาษาต้นฉบับ

ถอนการติดตั้งไคลเอนต์ผ่านการตั้งค่า Windows > แอป หรือทางลัดถอนการติดตั้งที่สร้างไว้ ค่าภาษาจะยังอยู่ การถอนการติดตั้งจะไม่ลบบัญชีหรือตัวละครบนเซิร์ฟเวอร์ ให้ยึดคู่มือนี้เป็นหลักเหนือหมายเหตุเก่าในไฟล์เก็บถาวรที่เก็บไว้เพื่ออ้างอิง

การอัปเดตอัตโนมัติ
ติดตั้ง r8 ครั้งเดียวแล้วเปิดเกมผ่านทางลัดบนเดสก์ท็อป โปรแกรมจะตรวจสอบรายการที่ลงลายเซ็นและดาวน์โหลดเฉพาะไฟล์ที่เปลี่ยน บันทึกความคืบหน้าและปิดเกมก่อนอัปเดต หากการแทนที่ไฟล์ล้มเหลวหรือหยุดกลางทางจะคืนค่าไฟล์เดิมก่อนเปิดเกม และจะย้อนกลับเมื่อการเปิดรุ่นใหม่ครั้งแรกล้มเหลว ดาวน์โหลดที่เสร็จแล้วจะใช้ซ้ำ ไฟล์ที่ยังไม่เสร็จจะดาวน์โหลดใหม่ ภาษาและตัวละครบนเซิร์ฟเวอร์จะยังคงอยู่ หากบริการอัปเดตใช้ไม่ได้ ยังเปิดรุ่นที่ติดตั้งและตรวจสอบแล้วได้
ขนาดการแสดงผล
ที่หน้าล็อกอิน เลือกขนาดหน้าต่างที่มุมล่างซ้าย แนะนำให้ใช้โหมดอัตโนมัติ หรือเลือกขนาดหน้าต่าง 4:3 ที่ใช้งานได้ ฉาก ข้อความ ปุ่ม และพื้นที่คลิกจะขยายพร้อมกัน ขนาดที่ใหญ่เกินหน้าจอจะเลือกไม่ได้ การเลือกจะถูกบันทึกไว้สำหรับการเปิดครั้งถัดไปและยังคงอยู่หลังอัปเดต ขนาดเหล่านี้ใช้กับโหมดหน้าต่าง ส่วนโหมดเต็มหน้าจอจะรักษาสัดส่วนเดิม
