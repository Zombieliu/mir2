# Invited playtest limitations / 邀請測試限制 / Limitações do teste

English: Testing covers levels 0–30. The Warrior path has player acceptance; full Wizard and Taoist routes still need it. The server is capped at 15 simultaneous players; this cap is not a capacity benchmark. The installer is not publicly Authenticode signed. The signed package manifest verifies internal integrity and is a separate mechanism. Report build ID, map, coordinates and reproduction steps with any issue. Player names, player chat and user-authored text keep their original language.

繁體中文：測試範圍為 0–30 級。戰士路線已完成人工驗收，法師與道士仍待全程驗收。伺服器限制同時在線 15 人；此限制不代表已通過 15 人壓力測試。安裝程式尚無公開 Authenticode 簽章，套件清單的完整性簽章是另一種機制。回報問題時請提供版本、地圖、座標及重現步驟。玩家姓名、聊天與自訂文字保留原語言。

Português (Brasil): O teste cobre os níveis 0–30. O percurso do Guerreiro foi aceito por um jogador; os percursos completos do Mago e do Taoista ainda precisam dessa validação. O servidor limita o acesso a 15 jogadores simultâneos; isso não comprova a capacidade sob carga. O instalador não tem assinatura pública Authenticode. A assinatura do manifesto verifica a integridade interna do pacote e é um mecanismo separado. Ao relatar problemas, informe a versão, o mapa, as coordenadas e os passos para reproduzir. Nomes, chat de jogadores e textos personalizados mantêm o idioma original.
