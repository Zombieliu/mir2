Pembaruan otomatis
Pasang r8 sekali, lalu klik dua kali pintasan desktop. Setelah verifikasi lokal berhasil, layar utama menyediakan Mulai game tanpa harus menunggu pemeriksaan pembaruan. Peluncur memeriksa informasi pembaruan yang ditandatangani di latar belakang tanpa otomatis mengunduh berkas pembaruan. Pembaruan biasa tidak menghalangi versi terpasang yang telah diverifikasi. Pilih Lihat pembaruan untuk melihat perkiraan jumlah data; layar konfirmasi menyediakan Mainkan versi saat ini dan Perbarui. Unduhan berkas yang berubah hanya dimulai setelah memilih Perbarui. Ukuran unduhan sebenarnya dapat berbeda sesuai cache dan paket transfer. Jendela menampilkan progres, kecepatan, dan perkiraan sisa waktu untuk unduhan saat ini. Setelah memperbarui, pilih Mulai game untuk menuju layar login. Jika pemeriksaan atau pembaruan gagal, pilih Coba lagi; versi terpasang tetap dapat dimainkan selama masih lolos verifikasi. Peluncuran hanya dinonaktifkan jika instalasi lokal rusak atau tidak dapat diverifikasi; perbaiki dengan pemasang tepercaya. Kompatibilitas dengan server ditangani saat login ke game. Simpan progres dan tutup game sebelum memperbarui. Aktivasi yang gagal atau terputus dipulihkan sebelum game dimulai; kegagalan awal pada versi baru juga memulihkan versi lama. Unduhan lengkap digunakan kembali, berkas yang belum lengkap diunduh ulang. Bahasa dan karakter di server tetap tersimpan.
