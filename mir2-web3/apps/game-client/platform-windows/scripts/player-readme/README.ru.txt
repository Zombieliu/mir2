Numeron - Legend of Rebirth — Тестирование по приглашению

Для Windows 10/11 x64. Установщик использует локальную папку программ вашего пользователя Windows и может создать ярлык на рабочем столе. Если среда Microsoft Visual C++ x64 отсутствует, Windows запросит права администратора для установки этого компонента Microsoft. При необходимости перезапустите Windows перед запуском игры.

Выберите English, 繁體中文, Português (Brasil), Русский, हिन्दी, Bahasa Indonesia, Tiếng Việt, ไทย или العربية. При первой установке этот выбор задаёт язык игры. Уже сохранённая настройка имеет приоритет. Язык можно изменить на экране входа или в настройках игры. Он сохраняется отдельно для пользователя Windows, вне папки игры. Имена игроков, введённые данные аккаунта и сообщения игроков не переводятся.

Запустите Numeron - Legend of Rebirth. Каждый игрок должен создать отдельный аккаунт. Идентификатор: 3–15 латинских букв или цифр. Пароль: 10–15 латинских букв или цифр; он должен отличаться от идентификатора и не быть распространённым слабым паролем. Не используйте один аккаунт одновременно на нескольких клиентах.
Сервер: wss://165.154.65.136.sslip.io/playtest/ws

Нажмите Q для заданий. Для перемещения используйте карту и подсказки заданий. Перед закрытием игры выполните обычный выход из персонажа, чтобы сохранить прогресс. Прогресс хранится на сервере; переустановка клиента его не сбрасывает.

Версия поддерживает девять языков интерфейса и содержит необходимые шрифты, включая связное арабское письмо, деванагари и тайское письмо. Сохранены исправления эффектов предпросмотра Мага, непрерывной анимации, тихого запуска и фиксированного размера окна в пикселях.

Если Windows блокирует запуск, в том числе с ошибкой 4551, не отключайте защиту приложений. Передайте разработчику код и журнал установки либо попросите администратора организации проверить политику. Запросите сборку с доверенной подписью. Внутренняя подпись целостности пакета не является подписью издателя Windows. Если безопасная папка пользователя доступна для записи, ошибка сохраняется в LocalAppData/mir2-web3/installer-last-launch.txt. Ошибка запуска не означает ошибку установки.

Это тестовая сборка по приглашению. Путь Воина с 0-го по 30-й уровень проверен игроком; полная проверка Мага и Даоса ещё требуется. Ограничение входа определяется текущей конфигурацией сервера. Стабильная работа при 50 или 100 игроках не заявляется. Некоторые имена собственные и серверные тексты могут сохранять исходный язык.

Удалите клиент через «Параметры Windows > Приложения» или ярлык удаления. Настройка языка сохраняется. Удаление клиента не удаляет аккаунты и персонажей на сервере. Это руководство имеет приоритет над старыми архивными примечаниями, оставленными для прослеживаемости.

Автоматические обновления
Установите r7 один раз и запускайте игру через ярлык. Программа проверяет подписанный список обновлений и загружает только изменённые файлы. Сохраните прогресс и закройте игру перед обновлением. При прерывании или ошибке замены прежние файлы восстанавливаются до запуска; ошибка первого запуска также вызывает откат. Завершённые загрузки используются повторно, незавершённые повторяются. Язык и персонажи на сервере сохраняются. Если сервис обновления недоступен, можно запустить проверенную установленную версию.
Размер изображения
На экране входа используйте кнопку «Размер окна» внизу слева. Рекомендуется режим «Авто», либо выберите доступный размер окна 4:3. Сцена, текст, кнопки и области нажатия масштабируются вместе. Слишком большие размеры недоступны. Выбор сохраняется для следующего запуска и после обновлений. Эти размеры относятся к оконному режиму; полноэкранный режим сохраняет исходные пропорции.
