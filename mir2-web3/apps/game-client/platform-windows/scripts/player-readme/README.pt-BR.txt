Numeron - Legend of Rebirth — Teste por convite

Instale no Windows 10/11 x64. O instalador usa a pasta local de programas do seu usuário do Windows e pode criar um atalho na área de trabalho. Se o runtime Microsoft Visual C++ x64 estiver ausente, o Windows solicitará permissão de administrador para esse componente da Microsoft. Reinicie o Windows se solicitado antes de abrir o jogo.

Escolha English, 繁體中文, Português (Brasil), Русский, हिन्दी, Bahasa Indonesia, Tiếng Việt, ไทย ou العربية. Na primeira instalação, essa escolha define o idioma inicial do jogo; uma preferência existente sempre tem prioridade. Você pode mudar o idioma na tela de login ou nas opções do jogo. A escolha é salva por usuário do Windows fora da pasta do jogo. Nomes de jogadores, dados de conta digitados e chat de jogadores permanecem como foram escritos.

Inicie Numeron - Legend of Rebirth. Cada jogador deve criar sua própria conta. O ID exige 3–15 letras ou números; a senha de cadastro exige 10–15 letras ou números, deve ser diferente do ID e não pode ser uma senha fraca comum. Não use a mesma conta simultaneamente em vários jogadores.

Pressione Q para abrir as missões. Use os controles do mapa e da orientação de missões para navegar. Saia normalmente do personagem para salvar o progresso antes de fechar o jogo. O progresso fica no servidor; reinstalar o cliente não o reinicia.

Esta versão oferece nove idiomas de interface e inclui fontes para as escritas suportadas, com ligação de letras árabes, devanágari e tailandês. Mantém as correções dos efeitos de prévia do Mago, da continuidade da animação, da inicialização sem console e do tamanho da janela em pixels fixos.

Se o Windows bloquear a inicialização, inclusive com o erro 4551, mantenha a proteção de aplicativos ativada. Envie o código e o registro de instalação ao desenvolvedor ou peça ao administrador da organização que revise a política. Solicite uma versão com assinatura confiável; a assinatura interna de integridade do pacote não é uma assinatura de editor do Windows. Se o local seguro do usuário permitir gravação, a falha será registrada em LocalAppData/mir2-web3/installer-last-launch.txt. Falha ao iniciar não significa falha na instalação.

Este é um teste por convite. O percurso do Guerreiro do nível 0 ao 30 foi testado; Mago e Taoista ainda precisam de validação completa por jogadores. O limite de entrada depende da configuração atual do servidor; não há alegação de capacidade estável para 50 ou 100 jogadores. Alguns nomes próprios e textos enviados pelo servidor podem manter o idioma original.

Desinstale em Configurações do Windows > Aplicativos ou pelo atalho instalado. A preferência de idioma é preservada. Nenhuma conta ou personagem do servidor é removido. Este guia tem prioridade sobre notas antigas de arquivos mantidas para rastreabilidade.

Atualizações automáticas
Instale o r8 uma vez e use o atalho da área de trabalho. O iniciador verifica a lista assinada e baixa apenas os arquivos alterados. Salve e feche o jogo antes de atualizar. Se a ativação falhar ou for interrompida, os arquivos anteriores são restaurados antes de iniciar; uma falha no primeiro início também reverte a atualização. Downloads concluídos são reutilizados; arquivos parciais são baixados novamente. O idioma e os personagens no servidor são preservados. Sem acesso ao serviço de atualização, a versão instalada e verificada ainda pode iniciar.
Tamanho da tela
Na tela de login, use Tamanho da janela no canto inferior esquerdo. O modo Automático é recomendado, ou escolha um tamanho de janela 4:3 disponível. O cenário, os textos, os botões e as áreas de clique aumentam juntos. Tamanhos que não cabem na tela ficam indisponíveis. A escolha é salva para a próxima abertura e preservada nas atualizações. Essas opções valem para o modo janela; a tela cheia mantém a proporção original.
