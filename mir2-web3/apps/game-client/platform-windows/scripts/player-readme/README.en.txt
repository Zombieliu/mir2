Automatic updates
Install r8 once, then double-click the desktop shortcut. After local verification, the home screen lets you choose Start game without waiting for update checks. The launcher checks signed update information in the background without automatically downloading update files. An ordinary update does not block the verified installed version. Choose View update to see the estimated update data; the confirmation page offers both Play current version and Update. Only choosing Update starts downloading changed files. Actual download size can vary with caching and transfer packages. The window shows progress, speed and estimated time remaining for the current download. After updating, choose Start game to continue to sign-in. If checking or updating fails, choose Retry; an installed version that still passes verification remains available to play. Launch is disabled if the local installation is damaged or cannot be verified; use a trusted installer to repair it. The game handles server compatibility during sign-in. Save and close the game before updating. Failed or interrupted activation restores the previous files before launch; a failed first start rolls back. Completed downloads are reused; partial files are retried. Language preferences and server-side characters are preserved.
Display size
On the login screen, use the Window size button at the lower left. Automatic is recommended, or choose a supported 4:3 window size. The scene, text, buttons and pointer targets scale together. Sizes that do not fit the screen are unavailable. Your selection is saved for the next launch and retained by updates. These choices apply to windowed mode; fullscreen keeps the original aspect ratio.
