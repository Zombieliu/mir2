# Mir2 宽屏摄像机与 HUD 重排实验

分支：`feat/mobile-wide-camera-hud`

## 目标

为 20:9、19.5:9 等超宽横屏手机提供独立的宽屏布局，不通过 `cover` 裁掉原始 4:3 HUD。

## 当前阶段：虚拟舞台与 HUD 外壳

通过 `?wideMobile=1` 开启实验模式（默认关闭）：

- 横屏虚拟舞台高度保持 768，宽度按设备比例扩展；
- 舞台缩放后覆盖真实横屏宽度，不再把 4:3 舞台整体塞进左右黑边；
- HUD 使用扩展后的舞台宽度，右侧小地图、状态栏等边缘组件跟随安全区，底部主 HUD 和聊天区域保持原始组合并居中；
- 触控栏使用真实屏幕宽度，不额外向舞台两侧申请旧的 128px rails；
- 默认不启用，因此桌面、TV 和普通 4:3/16:9 设备行为不变。

## 尚未完成

这不是最终的宽屏生产模式。下一阶段仍需要：

1. 根据虚拟舞台宽度扩展地图瓦片/实体预取窗口；
2. 让 DOM、WebGL2 和 Bevy 三条渲染路径共享同一套动态 viewport origin；
3. 更新鼠标/触控坐标、寻路点击、小地图和摄像机偏移；
4. 对边缘刷怪、技能范围和 PvP 视野做公平性验证；
5. 通过 iPhone、Android、PWA standalone 真机截图后再决定是否默认开启。

## 本地验收

```text
http://localhost:3000/?wideMobile=1
```

推荐横屏测试视口：`844×390`、`915×412`、`1311×603`。页面根节点应出现 `data-wide-mobile="true"`，`.client-stage-frame` 的 CSS 宽度应大于 1024px，舞台仍保持完整高度比例。
